# Spec: translation (engines, batching, retry, register, translation providers)

Scope: translation engines (Gemini, OpenAI-compatible, LibreTranslate), batching, retry, register probe, translation providers and the translate run. In scope as well: the translate route and its background run (rules 42-44, 47), which `subtitles.md` leaves to this spec. Out of scope: the cleaner (`subtitle-files.md`), the media ACL gate and `SFnew` shape (`subtitles.md` rules 2, 5), the engine `SubtitleToSrt` job (`engine-glue.md`). Subtitle download providers: `subtitle-providers.md`.

## Routes

9 routes under `/api/subtitles/translation-providers`, each needing a credential and a policy; `scope:'stream'` tokens are rejected. Static paths (`available`, `test-connection`, `models`) win over `:id`. Plus the translate route `POST /api/media/:id/subtitles/:subtitleId/translate` (last table row), 10 in all. `TranslationProviderJSON` = `{id, createdAt, updatedAt, name, engine: 'gemini'|'openai'|'libretranslate', enabled, isDefault, settings}` with `settings` redacted (rule 36): `apiKey` removed, `secretsSet: ['apiKey']|[]` added.

## Rules

### A. Engines, config, factory

1. Engines: `gemini`, `openai` (any OpenAI-compatible chat-completions endpoint), `libretranslate`; pg enum `translation_providers_engine_enum`. An engine value the factory does not know falls into the Gemini branch of `translate` (unreachable through the DTO).
2. Config parsing (`settings` is opaque jsonb): string keys are `typeof v === 'string' ? v.trim() : ''`; numeric knobs `maxTokensPerRequest`, `tokensPerMinute` are `Math.floor(Number(v))` when finite and `> 0`, else `0` (= no limit). Per engine: gemini `{apiKey, model (default 'gemini-3.5-flash-lite'), maxTokensPerRequest, tokensPerMinute}`; openai `{baseUrl, apiKey, model, maxTokensPerRequest, tokensPerMinute}`; libretranslate `{url, apiKey}`.
3. `validateConfig(engine, settings)` throws 400 (`BadRequestException`, message verbatim): gemini without key -> `Gemini API key is not set`; openai without `baseUrl` or `model` -> `An OpenAI-compatible base URL and model are required`; libretranslate without `url` -> `The LibreTranslate URL is not set`. An OpenAI-compatible endpoint needs no key (keyless Ollama), LibreTranslate none (self-hosted). (Rule 48.) A non-empty `baseUrl` / `url` that is not an `http(s)` URL with a host is rejected.
4. `resolveModel`: gemini -> the effective model, openai -> `model`, libretranslate -> `null` (stored on the subtitle row as provenance).
5. `TranslationRequest`: `{sourceLanguage (ISO 639-1, 'und'/'xx'/empty = unknown), targetLanguage, context: {title?, year?, mediaType?, genres?, overview?}, register?}`. `TranslationRateLimitError(scope: 'daily'|'per-minute'|'unknown')` and `TranslationPayloadTooLargeError` are the two typed failures.

### B. Transport and retry (`postWithRetry`, `getModelListing`)

6. Constants: request timeout 240000 ms; `MAX_ATTEMPTS = 4` (1 + 3 retries); retryable statuses `{429, 500, 502, 503, 504}`; quota floor wait 20000 ms; max wait 60000 ms; backoff before retry `n` (n = failed attempt, 1-based) = `min(1000 * 2^(n-1), 30000)` ms = 1 s, 2 s, 4 s.
7. Per attempt `fetch(url, {...init, signal: timeout(240000)})`. A thrown error (network, timeout) retries after `backoff(attempt)` until attempt 4, then throws `<Label> request failed after 4 attempts: <String(err)>`. A 2xx returns the unconsumed response.
8. On a non-2xx, `errText = await res.text()` (empty on failure) and: `quota = status === 429 || /rate.?limit|per minute|\bTPM\b|quota/i.test(errText)` (any status, body match is case-insensitive); `daily = quota && /PerDay|per day|requests per day/i.test(errText)`.
9. Too large: when `!quota` and (`status === 413` or `/context[_ ]length|too large|max_tokens/i` matches) throw `TranslationPayloadTooLargeError("<Label> rejected the request as too large: <errText>")`, no retry. A 413 that is a spent per-minute allowance (Groq `TPM`) is `quota`, so it waits and retries and never splits.
10. Retry: when `!daily && (quota || status in retryable) && attempt < 4`: WARN `<Label> answered <status> on attempt <n>/4, waiting: <errText first 200 chars>`; wait `min(max(suggested ?? 0, backoff(attempt), quota ? 20000 : 0), 60000)` ms, then the next attempt. `suggested` = `parseRetryDelayMs(errText)` when not null, else `Retry-After` header seconds * 1000 when finite and `> 0`, else none. Note a non-retryable status (400, 401) whose body matches the `quota` regex IS retried (rule 52).
11. `parseRetryDelayMs(body)`: `JSON.parse(body).error.details[]`, the first element with `retryDelay` string matching `^([\d.]+)s$` (e.g. `38s`, `38.5s`; not `1m`) -> `round(parseFloat * 1000)`; any parse failure -> null.
12. Terminal failures (after retries or without retry): if `quota`: throw `TranslationRateLimitError("<Label> quota/rate limit exceeded (scope=<s>[, retryDelay=<n>s]): <errText>", scope)` with `scope = daily ? 'daily' : /PerMinute/i matches ? 'per-minute' : 'unknown'`, `retryDelay` shown only when the body had one (rounded seconds). Otherwise `Error("<Label> API error <status>: <errText>")`. `daily` never retries (gives up on the first answer).
13. `getModelListing(url, headers, label)`: one GET, 15000 ms timeout, no retry; non-ok -> `Error("<Label> model list failed (<status>): <errText first 300 chars>")`; ok -> `res.json()`. Labels in messages: `Gemini`, `OpenAI-compatible`, `LibreTranslate`.

### C. Prompt, numbering and register

14. `buildPayload(texts)` = `texts.map((t,i) => "#<i+1>#\n" + t).join("\n")`. `parseNumbered(response, count)`: normalise `\r\n`; skip lines matching `^\s*` + three backticks; a line `^\s*#(\d+)#[ \t]*(.*)$` starts segment N (inline remainder is its first line, else empty); other lines append to the current segment (lines before any marker are dropped); a repeated number REPLACES the earlier one; result = segments `1..count` each `join("\n").trim()`; any missing number -> `null` (the caller splits). Extra numbers beyond `count` are ignored.
15. `buildSystemInstruction(req)` (exact text matters: vectors pin it): line 1 `You are a professional subtitle translator. Translate the subtitle segments from <name(source)> to <name(target)>.<contextLine><synopsis><register>`; `name(iso)` = `the original language` for unknown codes, else the `APP_LANGUAGES` name, else the code; `contextLine` = ` This is a <series|movie> titled "<title>" (<year>), genres: <g1, g2>.` built from the present parts (`series` only when `mediaType === 'series'`; empty when no title and no genres); `synopsis` = ` Synopsis: <overview trimmed, first 300 chars>` when non-blank. Then 6 fixed lines (the `#N#` explanation, same order/numbers, multi-line segments as one sentence, not longer in characters than the source, keep proper nouns / concise, output only numbered translations), joined with `\n`. The text is a Rust constant, pinned by the vectors.
16. Register (second-person form) exists for 7 target languages: `fr tu/vous`, `de du/Sie`, `es tú/usted`, `it tu/Lei`, `pt tu/você`, `nl je/u`, `ru ты/вы` (informal/formal). `hasRegisterChoice(target)` = key present.
17. `registerSample(texts, windows=3, perWindow=12)`: when `texts.length <= windows*perWindow` -> all texts; else for `w = 0..windows-1` the run `texts[start .. start+perWindow)` with `start = floor((w+1)*len/(windows+1))`, each run followed by an empty string. Consecutive cues, not every Nth.
18. `buildRegisterProbe(req, sample)`: null when the target has no register; else `system` = `These are subtitles from a <series|film> being translated into <name(target)>. Judging from how the characters speak to each other, answer with exactly one word, "<informal>" or "<formal>", naming the second-person form they would use. Answer with that word alone.` (`series` only for `mediaType === 'series'`), `user` = `sample.join("\n")`.
19. `parseRegister(answer, target)`: null without a register; strip a leading `^\s*<think>[\s\S]*?(</think>|$)` (case-insensitive; an unterminated block strips to the end); words = lower-cased `[\p{L}]+` matches; `informal` / `formal` = whether each lower-cased form is among the words; both or neither -> `null`; else the form with its configured casing (`Sie`, `Lei`). A bare answer like `Tu\n`, `  vous.` works; `Pas tu, mais vous.` is refused.
20. `withRegister(req, texts, ask)`: returns `req` unchanged when `req.register` is already set or the target has no register or the probe is null. Otherwise one `ask(system, user)` call; an unparseable answer logs WARN and returns `req`; a thrown error logs WARN and returns `req` (the translation never fails because of the probe); success returns `{...req, register}`. The probe goes through `postWithRetry` (so it can wait up to the retry budget).
21. When a register is resolved the system prompt gains ` These speakers use "<register>" with each other. Use it wherever a line gives no clear indication of its own, set phrases included; where a line clearly shows a different relationship, use "<other>" instead.`; nothing is added otherwise, or when the target has no register.

### D. Batching (`translateWithBatching`)

22. Inputs: `texts`, `callBatch(batch, maxOutputTokens) -> string[] | null` (null = does not map), `limits {maxTokensPerRequest, tokensPerMinute, key, outputCeiling, batchCeiling}`, `systemInstruction`, `onProgress(done, total)`. Constants: `MAX_OUTPUT_TOKENS 8192`, `BATCH_SIZE 150`, `MIN_TOKENS_PER_REQUEST 2048`, `CHARS_PER_TOKEN 4`, `MARKER_TOKENS 4`, `MAX_CONSECUTIVE_MISMATCHES 3`; `estimateTokens(t) = ceil(len / 4)` (`len` in UTF-16 code units: `encode_utf16().count()`).
23. A configured `maxTokensPerRequest` in `(0, 2048)` is raised to 2048 (WARN). `ceiling = max(1, batchCeiling)` (a zero ceiling must not loop forever).
24. Top-level cut `batchEnd(texts, from, systemTokens, {batchCeiling: ceiling})`: `max = min(from + ceiling, len)`; `budget = maxTokensPerRequest ? (maxTokensPerRequest - systemTokens)/3 : outputCeiling/2`; accumulate `estimateTokens(text) + 4` from `from`; return the first `i > from` where `used > budget`, else `max`. A batch holds at least one cue.
25. Per batch: `prompt = systemTokens + sum(estimateTokens(t) + 4)`; `output = max(256, min(outputCeiling, room, prompt*2))` with `room = maxTokensPerRequest ? maxTokensPerRequest - prompt : outputCeiling` (scaled to the batch, never a flat maximum).
26. Pacing (`tokensPerMinute > 0`): fixed 60 s window per `limits.key`, process-wide map `{start, used}`. Before a call reserve `prompt + output`: if the window is older than 60 s reset it; if `used === 0 || used + tokens <= tokensPerMinute` take it; else sleep until `start + 60000` and re-check (a request larger than the allowance still goes alone in a fresh window). Keys: gemini `gemini:<model>`, openai `openai:<url>:<model>`.
27. Split algorithm `translateBatchWithSplit(texts)` (empty -> `[]`): reserve rate, call. A `TranslationPayloadTooLargeError` (any other error propagates and fails the run, no split): for 1 cue -> WARN, `report(1)`, keep the source text (counts toward `kept`); else `truncated = true`, `shrink(len)` (`ceiling = max(1, min(ceiling, floor(len/2)))`) and split. A result whose length equals the batch -> `report(len)`, reset the mismatch counter, return it. A `null` or wrong-length result: for 1 cue -> `trackMismatch(false)`, `report(1)`, keep source; else (WARN unless `truncated`) split at `mid = floor(len/2)`, left then right, sequentially, concatenated. Splitting by mismatch does NOT shrink the ceiling.
28. `trackMismatch(false)` increments a counter, `trackMismatch(true)` zeroes it; at 3 consecutive single-cue mismatches throw `3 consecutive cues failed to map back to the engine's response, aborting the run`. After the loop, when `texts.length > 0 && kept === texts.length` throw the last keep error (or `translation produced no translated cues`): an untranslated file is never a success. Progress: `onProgress(done, total)` after every group that comes back, halves included (`done` is cumulative cues); the engine order is preserved.
29. Rust layout: pure parts (`estimate_tokens`, `batch_end`, `reserve_output`, the split state machine over an injected `call_batch` and `sleep`/clock, `parse_numbered`, register functions, prompt builders, `classify_failure(status, body, retry_after) -> Retry{wait_ms} | TooLarge | RateLimit{scope, retry_delay} | Error` and the backoff arithmetic) in `fliks_domain::translation`; HTTP in the server crate. The vectors replay the pure functions with scripted engines and a virtual clock.

### E. Engines

30. Gemini: `POST https://generativelanguage.googleapis.com/v1beta/models/<enc model>:generateContent` with header `x-goog-api-key`, JSON `{systemInstruction:{parts:[{text: system}]}, contents:[{role:'user', parts:[{text: user}]}], generationConfig:{temperature, maxOutputTokens, ...thinkingConfig}}`. Probe: `temperature 0`, `maxOutputTokens 500` (`REGISTER_PROBE_MAX_OUTPUT_TOKENS`, enough for a thinking model to still land the word). Batch: `temperature 0.3`, `maxOutputTokens` = the reservation, user = `buildPayload(batch)`. `thinkingConfig`: model `^gemini-3` -> `{thinkingConfig:{thinkingLevel:'low'}}`, `^gemma-4` -> `{thinkingLevel:'minimal'}`, others none. Limits: `outputCeiling 65536`, `batchCeiling 500`, key `gemini:<model>`. Response text = `candidates[0].content.parts[*].text` joined (missing -> ''). `finishReason === 'MAX_TOKENS'` -> `TranslationPayloadTooLargeError("Gemini truncated <n> cues at the output budget (usage=<json>)")`; `parts` not an array -> WARN and `null`; else `parseNumbered(joined, n)`.
31. Gemini key transport: header `x-goog-api-key`; no URL containing the key is ever built, so the key never lands in a logged URL or an error (`subtitle-providers.md` rule 49).
32. OpenAI-compatible: `url = baseUrl` with trailing `/` runs removed `+ "/chat/completions"`; headers `Content-Type: application/json` and `Authorization: Bearer <key>` only when the key is non-empty; body `{model, temperature, max_tokens, messages:[{role:'system', content: system}, {role:'user', content: user}]}`; probe `temperature 0`, `max_tokens 500`; batch `temperature 0.3`, `max_tokens` = the reservation. Limits: `outputCeiling 8192`, `batchCeiling 150`, key `openai:<url>:<model>` (`<url>` = the full `.../chat/completions` URL). Response `choices[0]`: `finish_reason === 'length'` -> `TranslationPayloadTooLargeError("OpenAI-compatible endpoint truncated <n> cues at its context limit (usage=<json>); set maxTokensPerRequest to what it actually accepts")`; `message.content` not a string -> `null`; else `parseNumbered`. Probe answer = `String(content ?? '')` (a `<think>` block is stripped by rule 19).
33. OpenAI model listing: `GET <baseUrl without trailing />/models` with the bearer header; `data[].id` strings, non-empty, sorted ascending (code-unit order). Gemini listing: `GET .../v1beta/models?pageSize=1000` with the `x-goog-api-key` header, keep models whose `supportedGenerationMethods` contains `generateContent`, strip the `models/` prefix, sort ascending. LibreTranslate: `[]`, no request.
34. LibreTranslate: no prompt, no register, no pacing, no splitting. `url = url without trailing /` `+ "/translate"`; `source = 'auto'` when the source is unknown (`''`, `und`, `xx`), else the code; chunks of 25 cues; per chunk `POST` JSON `{q: [texts], source, target: targetLanguage, format: 'text', api_key?}` (`api_key` in the JSON body only when non-empty) through `postWithRetry`; `translatedText` array of the chunk's length (or a string for a one-cue chunk) -> `String()` of each; any other shape -> WARN and the chunk keeps its source text. `onProgress(min(i+25, len), len)` after each chunk. When `len > 0` and zero chunks translated throw `LibreTranslate returned no usable translation for any chunk`.

### F. Translation providers (entity, CRUD, secrets, test)

35. Entity `translation_providers`: `id`, `createdAt`, `updatedAt`, `name` varchar, `engine` pg enum, `enabled` bool default true, `isDefault` bool default false, `settings` jsonb default `{}`; `subtitle_files.translationProviderId` FK `ON DELETE SET NULL`, plus `translationProviderName`, `translationEngine`, `translationModel` varchar (snapshots taken at trigger time).
36. Secret field: `apiKey` only (`secretsSet`). The provider secrets are redacted on every route that returns a provider; `GET .../available` never has settings.
37. Defaults: `create` saves, then when `isDefault` clears every other default (`UPDATE ... SET "isDefault" = false WHERE id != $1 AND "isDefault" = true`); `update` does the same when `dto.isDefault === true`; `isDefault:false` on the default leaves none. Create/update and the default switch run in one transaction with `SELECT ... FOR UPDATE` on the default rows, so concurrent saves never leave two defaults or none. `remove` of the default promotes the first enabled row by `id ASC` (if it is not already default); disabling the default does not re-promote. `findDefault` (used when a translate call has no provider) = the enabled default, else the first enabled by `isDefault DESC, id ASC`, else null.
38. `create`: `settings = mergeSecretFields(undefined, dto.settings ?? {})` (null/blank `apiKey` dropped), `enabled ?? true`, `isDefault ?? false`. `update` (404 first): `name`, `engine`, `enabled`, `isDefault` when `!== undefined`; `settings` when defined: `nextEngine = dto.engine ?? stored.engine`, `carryOver = sameEndpoint(stored.engine, stored.settings, nextEngine, dto.settings)` (same engine AND, for openai `settings.baseUrl === stored baseUrl`, for libretranslate `settings.url === stored url`, gemini has no endpoint), then `mergeSecretFields(carryOver ? stored.settings : undefined, dto.settings)`: blank/absent `apiKey` keeps the stored one only on carry-over, `null` erases. `sameEndpoint` compares after trimming and removing trailing `/` (`http://h/` equals `http://h`), and a stored key is dropped on an engine change whether or not `settings` is sent. An engine or host edit therefore drops the stored key.
39. `test-connection` and `models` resolve a blank `apiKey` from the stored row of `id` through `resolveStoredSecrets` only when `sameEndpoint(...)` holds (same engine, same host); otherwise the request goes with exactly what was sent.
40. `testConnection(engine, settings, id?)`: inside one try, `validateConfig` (its 400 becomes `ok:false`, never an HTTP 400), then a real `translate(['Hello.', 'Good morning.'], en -> fr, no context)` (Gemini/OpenAI: TWO requests, register probe then batch, through the normal retry path; LibreTranslate: one); `ok:true` when the output is non-empty, `{ok:false, error:'Empty translation response'}` for an empty one, any thrown error -> `{ok:false, error: <message>}` (status 201 either way; messages of rules 3, 7, 12). `POST :id/test` runs it with the stored `(engine, settings)`.
41. `listModels(engine, settings, id?)`: the factory call of rule 33; a thrown `HttpException` (the 400 key/base-URL messages) passes through, anything else becomes `502` with the error message.

### G. How a run uses the engines (caller contract)

42. `translateSubtitle(subtitleId, targetLanguage, providerId?)`, in order: `subtitle_translation_enabled` must be `'true'` else 400 `errors.translation_disabled`; provider = the requested one (404 `TranslationProvider #<id> not found`; disabled -> 409 `errors.translation_provider_disabled`) or `findDefault()` (none -> 400 `errors.no_translation_provider`); `validateConfig` (400, rule 3); source row with `media, mediaFile, episode` (404 `Subtitle #<id> not found`); image codec -> 400 `errors.subtitle_needs_ocr`; no `relativePath` and no `streamIndex` -> 400 `errors.subtitle_no_readable_text`; `target = normalizeLanguageCode(targetLanguage)` (`und` for blank/missing) -> `und` gives 400 `errors.target_language_required`, equal to the source language 400 `errors.source_target_language_same`; `hearingImpaired = source.hearingImpaired && subtitle_remove_hi_tags !== 'true'`; duplicate guard keyed `mediaFileId:episodeId:target:forced:hearingImpaired` (an in-process set, then a PROCESSING `translated` row with those values) -> 409 `errors.already_running`. Then INSERT the placeholder `{media, mediaFile, episode, language: target, forced, hearingImpaired, providerType: 'translated', status: 'processing', codec: 'subrip', score: source.score, translationProvider: {id}, translationProviderName, translationEngine, translationModel: resolveModel (rule 4)}` and return it (`SFnew`); the run starts detached.
43. Run: media without `path` fails (`media root folder not set`); source SRT = the sidecar read as UTF-8 when `codec === 'subrip'` or the path ends `.srt`, else engine job `SubtitleToSrt` (file source; an embedded track: stream source, needs `streamInfo` and `streamIndex`, `priority: 'high'`); `parseSrt` (rule 47) with zero cues fails (`source subtitle has no text`); `context {title, year, mediaType: media.type, genres, overview}`, `register` unset (rule 20); `onProgress(0, n)` is emitted BEFORE the slot gate; the gate admits at most `subtitle_translation_max_concurrency` (read at trigger time) runs into `translate`, others wait FIFO. Each progress call stores `round(done/total*100)` (read back by `GET /api/media/:id/subtitles` as `translationProgress`) and emits `subtitle.translation_progress {subtitleId, mediaId, progress}`.
44. Result: per cue `translated[i] || source` (`mergeTranslated`), `serializeSrt`, the cleaner with `removeAds: true`, `removeHiTags`, `subtitle_custom_exclusions` lines; suffix `<target>.forced` / `<target>.hi` / `<target>` through `assertSafeLangSuffix` (a bad target fails the run here, after the placeholder exists); path `<video name>.<suffix>.srt`, then `<suffix>-1`, `-2`… until free; write; the path is confined to the media root BEFORE the write (`subtitle-files.md`); UPDATE `{relativePath, hearingImpaired, status: 'downloaded'}`; SSE `subtitle.downloaded {mediaId, title, language, provider: <provider name>, subtitleId, reason: 'translation'}`. Failure: SSE `subtitle.failed {mediaId, title, language, error: String(err), reason: 'rate_limit'|'translation', scope}` (upstream text cut at 300 characters, rule 48), the row kept as `failed` with `errorMessage` = `errors.translation_rate_limited_daily` (scope `daily`) / `errors.translation_rate_limited` / `errors.translation_too_large` / `String(err).slice(0, 2000)`. Progress entry dropped either way. At boot every PROCESSING `translated` row becomes failed with `activity.subtitle_error_interrupted`.
47. `parseSrt`: strip a leading BOM, normalise CRLF/CR to LF, split blocks on `\n[ \t]*\n`; in a block every line containing `-->` starts a cue (timing = that line trimmed); its text runs to the next timing line, minus a bare `^\d+$` index line just before it; text joined with `\n` and trimmed; empty text drops the cue. `serializeSrt` = `<i+1>\n<timing>\n<text>` joined with `\n\n` plus a final `\n`.

### H. Outbound HTTP in tests and parity

45. Engine functions take the endpoint base as a parameter: openai/libretranslate take `baseUrl`, `url` from settings (so a stub URL goes in the provider's settings); Gemini's `https://generativelanguage.googleapis.com/v1beta` is a struct field defaulting to that constant and overridden only in tests. No production env switch for it. The mock OpenAI-compatible server is an axum stub serving `/v1/chat/completions` and `/v1/models`: the stub parses `#N#` payloads and answers `#N#\n<text>!`, with modes for `finish_reason: "length"`, 429 with `Retry-After`, 413 TPM body, wrong count, `<think>` prefix on the probe, and a hang (timeout test on a paused clock).
46. Parity: a provider pointing at `127.0.0.1:<stub>` is a black-box scenario only if the runner starts a stub; it does not. Parity covers CRUD, redaction, validation, `available`, `models`/`test-connection` with missing config (400 / `ok:false` without network).

### I. Decisions

48. `baseUrl` (openai) and `url` (libretranslate) are admin-set free strings; local Ollama / LibreTranslate on a private address is the intended use, so private ranges are not blocked. On create, update, `test-connection`, `models` and a run, a non-empty value that is not `http`/`https` with a host is 400 (`The OpenAI-compatible base URL must be an http(s) URL` / `The LibreTranslate URL must be an http(s) URL`; `ok:false` on `test-connection`, rule 40); engine requests follow no redirect; the upstream error text reaching a body, SSE event or row is cut at 300 chars everywhere (the full body still decides the quota and too-large cases). Errors, logs and bodies never carry a request URL or a configured secret (rule 31).
49. A typed `baseUrl` / `url` with a typed key goes where the admin pointed it (`test-connection` and `models` merge the stored key only when engine and host match, rule 39): accepted, admin only (`settings.access`), no change.
50. The 8 `subtitle_translation_*` engine keys are ignored by the translation code (`translate` uses the provider row); `GET /api/settings` keeps listing them, redacted (`settings.md`).
51. Redirects on engine requests are not followed (rule 48): an Ollama or LibreTranslate behind a redirecting proxy is configured with its final URL.
52. The body-regex quota detection applies to any status (rule 10): a 401 whose body says "rate limit" waits a minute, which only costs test-connection latency.
53. The pacing buckets (rule 26) and the slot gate (rule 43) are per process: fine with one `fliks-server`.

## SQL

`SELECT * FROM translation_providers ORDER BY "isDefault" DESC, name ASC` (list); `WHERE id = $1` (get); `WHERE enabled = true ORDER BY "isDefault" DESC, id ASC` (enabled / default / available); `INSERT`, `UPDATE` by id (save of the loaded row), `DELETE` by id; `clearOtherDefaults` and `promoteNextDefault` as in rule 37 (`WHERE enabled = true ORDER BY id ASC LIMIT 1`).  `create`/`update` + default switch run in one transaction (rule 37).
