1. Engines: `gemini`, `openai` (any OpenAI-compatible chat-completions endpoint), `libretranslate`; pg enum `translation_providers_engine_enum`. ### B. Transport and retry (`postWithRetry`, `getModelListing`)

6. Constants: request timeout 240000 ms; `MAX_ATTEMPTS = 4` (1 + 3 retries); retryable statuses `{429, 500, 502, 503, 504}`; quota floor wait 20000 ms; max wait 60000 ms; backoff before retry `n` (n = failed attempt, 1-based) = `min(1000 * 2^(n-1), 30000)` ms = 1 s, 2 s, 4 s. `[ts:src/modules/subtitles/translation-core.ts:55]`-`[ts:src/modules/subtitles/translation-core.ts:96]`
7. Per attempt `fetch(url, {...init, signal: timeout(240000)})`. A thrown error (network, timeout) retries after `backoff(attempt)` until attempt 4, then throws `<Label> request failed after 4 attempts: <String(err)>`. A 2xx returns the unconsumed response. `[ts:src/modules/subtitles/translation-core.ts:137]`-`[ts:src/modules/subtitles/translation-core.ts:159]`
8. On a non-2xx, `errText = await res.text()` (empty on failure) and: `quota = status === 429 || /rate.?limit|per minute|\bTPM\b|quota/i.test(errText)` (any status, body match is case-insensitive); `daily = quota && /PerDay|per day|requests per day/i.test(errText)`. `[ts:src/modules/subtitles/translation-core.ts:161]`-`[ts:src/modules/subtitles/translation-core.ts:168]`
9. Too large: when `!quota` and (`status === 413` or `/context[_ ]length|too large|max_tokens/i` matches) throw `TranslationPayloadTooLargeError("<Label> rejected the request as too large: <errText>")`, no retry. A 413 that is a spent per-minute allowance (Groq `TPM`) is `quota`, so it waits and retries and never splits. `[ts:src/modules/subtitles/translation-core.ts:162]`-`[ts:src/modules/subtitles/translation-core.ts:177]`, spec `[ts:src/modules/subtitles/translation-retry.spec.ts:45]`-`[ts:src/modules/subtitles/translation-retry.spec.ts:81]`
10. Retry: when `!daily && (quota || status in retryable) && attempt < 4`: WARN `<Label> answered <status> on attempt <n>/4, waiting: <errText first 200 chars>`; wait `min(max(suggested ?? 0, backoff(attempt), quota ? 20000 : 0), 60000)` ms, then the next attempt. `suggested` = `parseRetryDelayMs(errText)` when not null, else `Retry-After` header seconds * 1000 when finite and `> 0`, else none. Note a non-retryable status (400, 401) whose body matches the `quota` regex IS retried (kept: rule 52). `[ts:src/modules/subtitles/translation-core.ts:178]`-`[ts:src/modules/subtitles/translation-core.ts:204]`
11. `parseRetryDelayMs(body)`: `JSON.parse(body).error.details[]`, the first element with `retryDelay` string matching `^([\d.]+)s$` (e.g. `38s`, `38.5s`; not `1m`) -> `round(parseFloat * 1000)`; any parse failure -> null. `[ts:src/modules/subtitles/translation-core.ts:101]`-`[ts:src/modules/subtitles/translation-core.ts:116]`
12. Terminal failures (after retries or without retry): if `quota`: throw `TranslationRateLimitError("<Label> quota/rate limit exceeded (scope=<s>[, retryDelay=<n>s]): <errText>", scope)` with `scope = daily ? 'daily' : /PerMinute/i matches ? 'per-minute' : 'unknown'`, `retryDelay` shown only when the body had one (rounded seconds). Otherwise `Error("<Label> API error <status>: <errText>")`. `daily` never retries (gives up on the first answer). `[ts:src/modules/subtitles/translation-core.ts:205]`-`[ts:src/modules/subtitles/translation-core.ts:219]`
13. `getModelListing(url, headers, label)`: one GET, 15000 ms timeout, no retry; non-ok -> `Error("<Label> model list failed (<status>): <errText first 300 chars>")`; ok -> `res.json()`. Labels in messages: `Gemini`, `OpenAI-compatible`, `LibreTranslate`. `[ts:src/modules/subtitles/translation-core.ts:118]`-`[ts:src/modules/subtitles/translation-core.ts:130]`, spec `[ts:src/modules/subtitles/translation-model-listing.spec.ts:39]`-`[ts:src/modules/subtitles/translation-model-listing.spec.ts:44]`

### C. Prompt, numbering and register

14. `buildPayload(texts)` = `texts.map((t,i) => "#<i+1>#\n" + t).join("\n")`. `parseNumbered(response, count)`: normalise `\r\n`; skip lines matching `^\s*` + three backticks; a line `^\s*#(\d+)#[ \t]*(.*)$` starts segment N (inline remainder is its first line, else empty); other lines append to the current segment (lines before any marker are dropped); a repeated number REPLACES the earlier one; result = segments `1..count` each `join("\n").trim()`; any missing number -> `null` (the caller splits). Extra numbers beyond `count` are ignored. `[ts:src/modules/subtitles/translation-core.ts:382]`-`[ts:src/modules/subtitles/translation-core.ts:413]`
15. `buildSystemInstruction(req)` (exact text matters: vectors pin it): line 1 `You are a professional subtitle translator. Translate the subtitle segments from <name(source)> to <name(target)>.<contextLine><synopsis><register>`; `name(iso)` = `the original language` for unknown codes, else the `APP_LANGUAGES` name (`src/common/constants/app-languages.ts`), else the code; `contextLine` = ` This is a <series|movie> titled "<title>" (<year>), genres: <g1, g2>.` built from the present parts (`series` only when `mediaType === 'series'`; empty when no title and no genres); `synopsis` = ` Synopsis: <overview trimmed, first 300 chars>` when non-blank. Then 6 fixed lines (the `#N#` explanation, same order/numbers, multi-line segments as one sentence, no longer in characters than the source, keep proper nouns / concise, output only numbered translations), joined with `\n`. The text lives in the TS file at the cited lines; copy it into the Rust constant and the vectors. `[ts:src/modules/subtitles/translation-core.ts:344]`-`[ts:src/modules/subtitles/translation-core.ts:380]`
16. Register (second-person form) exists for 7 target languages: `fr tu/vous`, `de du/Sie`, `es tú/usted`, `it tu/Lei`, `pt tu/você`, `nl je/u`, `ru ты/вы` (informal/formal). `hasRegisterChoice(target)` = key present. `[ts:src/modules/subtitles/translation-core.ts:229]`-`[ts:src/modules/subtitles/translation-core.ts:242]`

Consecutive cues, not every Nth. `[ts:src/modules/subtitles/translation-core.ts:287]`-`[ts:src/modules/subtitles/translation-core.ts:299]`, spec `[ts:src/modules/subtitles/translation-register.spec.ts:84]`-`[ts:src/modules/subtitles/translation-register.spec.ts:98]`

Judging from how the characters speak to each other, answer with exactly one word, "<informal>" or "<formal>", naming the second-person form they would use. Answer with that word alone.` (`series` only for `mediaType === 'series'`), `user` = `sample.join("\n")`. `[ts:src/modules/subtitles/translation-core.ts:252]`-`[ts:src/modules/subtitles/translation-core.ts:262]`
19. `parseRegister(answer, target)`: null without a register; strip a leading `^\s*<think>[\s\S]*?(</think>|$)` (case-insensitive; an unterminated block strips to the end); words = lower-cased `[\p{L}]+` matches; `informal` / `formal` = whether each lower-cased form is among the words; both or neither -> `null`; else the form with its configured casing (`Sie`, `Lei`). Otherwise one `ask(system, user)` call; an unparseable answer logs WARN and returns `req`; a thrown error logs WARN and returns `req` (the translation never fails because of the probe); success returns `{...req, register}`. The probe goes through `postWithRetry` (so it can wait up to the retry budget). `[ts:src/modules/subtitles/translation-core.ts:306]`-`[ts:src/modules/subtitles/translation-core.ts:329]`, spec `[ts:src/modules/subtitles/translation-register.spec.ts:100]`-`[ts:src/modules/subtitles/translation-register.spec.ts:111]`

### D. Batching (`translateWithBatching`)

22. Inputs: `texts`, `callBatch(batch, maxOutputTokens) -> string[] | null` (null = does not map), `limits {maxTokensPerRequest, tokensPerMinute, key, outputCeiling, batchCeiling}`, `systemInstruction`, `onProgress(done, total)`. Constants: `MAX_OUTPUT_TOKENS 8192`, `BATCH_SIZE 150`, `MIN_TOKENS_PER_REQUEST 2048`, `CHARS_PER_TOKEN 4`, `MARKER_TOKENS 4`, `MAX_CONSECUTIVE_MISMATCHES 3`; `estimateTokens(t) = ceil(len / 4)` (`len` in UTF-16 code units in TS; Rust uses the same unit: `encode_utf16().count()`). `[ts:src/modules/subtitles/translation-core.ts:44]`-`[ts:src/modules/subtitles/translation-core.ts:70]`, `[ts:src/modules/subtitles/translation-core.ts:581]`-`[ts:src/modules/subtitles/translation-core.ts:587]`
23. A configured `maxTokensPerRequest` in `(0, 2048)` is raised to 2048 (WARN). `ceiling = max(1, batchCeiling)` (a zero ceiling must not loop forever). `[ts:src/modules/subtitles/translation-core.ts:588]`-`[ts:src/modules/subtitles/translation-core.ts:600]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:165]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:203]`
24. Top-level cut `batchEnd(texts, from, systemTokens, {batchCeiling: ceiling})`: `max = min(from + ceiling, len)`; `budget = maxTokensPerRequest ? (maxTokensPerRequest - systemTokens)/3 : outputCeiling/2`; accumulate `estimateTokens(text) + 4` from `from`; return the first `i > from` where `used > budget`, else `max`. A batch holds at least one cue. `[ts:src/modules/subtitles/translation-core.ts:446]`-`[ts:src/modules/subtitles/translation-core.ts:463]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:39]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:80]`
25. Per batch: `prompt = systemTokens + sum(estimateTokens(t) + 4)`; `output = max(256, min(outputCeiling, room, prompt*2))` with `room = maxTokensPerRequest ? maxTokensPerRequest - prompt : outputCeiling` (scaled to the batch, never a flat maximum). `[ts:src/modules/subtitles/translation-core.ts:423]`-`[ts:src/modules/subtitles/translation-core.ts:442]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:23]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:37]`
26. Pacing (`tokensPerMinute > 0`): fixed 60 s window per `limits.key`, process-wide map `{start, used}`. Before a call reserve `prompt + output`: if the window is older than 60 s reset it; if `used === 0 || used + tokens <= tokensPerMinute` take it; else sleep until `start + 60000` and re-check (a request larger than the allowance still goes alone in a fresh window). Keys: gemini `gemini:<model>`, openai `openai:<url>:<model>`. `[ts:src/modules/subtitles/translation-core.ts:465]`-`[ts:src/modules/subtitles/translation-core.ts:490]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:254]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:286]`
27. Split algorithm `translateBatchWithSplit(texts)` (empty -> `[]`): reserve rate, call. A `TranslationPayloadTooLargeError` (any other error propagates and fails the run, no split): for 1 cue -> WARN, `report(1)`, keep the source text (counts toward `kept`); else `truncated = true`, `shrink(len)` (`ceiling = max(1, min(ceiling, floor(len/2)))`) and split. A result whose length equals the batch -> `report(len)`, reset the mismatch counter, return it. A `null` or wrong-length result: for 1 cue -> `trackMismatch(false)`, `report(1)`, keep source; else (WARN unless `truncated`) split at `mid = floor(len/2)`, left then right, sequentially, concatenated. Splitting by mismatch does NOT shrink the ceiling. `[ts:src/modules/subtitles/translation-core.ts:492]`-`[ts:src/modules/subtitles/translation-core.ts:569]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:82]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:163]`
28. `trackMismatch(false)` increments a counter, `trackMismatch(true)` zeroes it; at 3 consecutive single-cue mismatches throw `3 consecutive cues failed to map back to the engine's response, aborting the run`. After the loop, when `texts.length > 0 && kept === texts.length` throw the last keep error (or `translation produced no translated cues`): an untranslated file is never a success. Progress: `onProgress(done, total)` after every group that comes back, halves included (`done` is cumulative cues); the engine order is preserved. `[ts:src/modules/subtitles/translation-core.ts:604]`-`[ts:src/modules/subtitles/translation-core.ts:653]`, spec `[ts:src/modules/subtitles/translation-batching.spec.ts:99]`-`[ts:src/modules/subtitles/translation-batching.spec.ts:252]`
29. [new] Rust layout: pure parts (`estimate_tokens`, `batch_end`, `reserve_output`, the split state machine over an injected `call_batch` and `sleep`/clock, `parse_numbered`, register functions, prompt builders, `classify_failure(status, body, retry_after) -> Retry{wait_ms} | TooLarge | RateLimit{scope, retry_delay} | Error` and the backoff arithmetic) in `fliks_domain::translation`; HTTP in the server crate. The vectors replay the pure functions with scripted engines and a virtual clock.

### I. Decisions settled in review

48. [new] F57 (security): `baseUrl` (openai) and `url` (libretranslate) are admin-set free strings: Nest does no scheme check, so `file:`, `gopher:` or a link-local or metadata address reaches `fetch` or fails late, and `models` / `test-connection` echo up to 300 chars of the upstream body (`test-connection`: the whole `errText`). Local Ollama / LibreTranslate on a private address is the intended use, so private ranges are not blocked. Rust: on create, update, `test-connection`, `models` and a run, a non-empty value that is not `http`/`https` with a host is 400 (`The OpenAI-compatible base URL must be an http(s) URL` / `The LibreTranslate URL must be an http(s) URL`; `ok:false` on `test-connection`, rule 40); engine requests follow no redirect; the echoed upstream text is cut at 300 chars everywhere. A sane configuration is unaffected.
49. A typed `baseUrl` / `url` with a typed key goes where the admin pointed it (`test-connection` and `models` merge the stored key only when engine and host match, rule 39): accepted, admin only (`settings.access`), no change.
50. The 8 legacy `subtitle_translation_*` engine keys stay until S9 (a delete migration is cheap then, and `GET /api/settings` keeps listing them, redacted): they are dead in Nest, Rust ignores them and `settings.md` keeps them redacted.
51. Redirects on engine requests are not followed (rule 48; Nest follows them, the `fetch` default): an Ollama or LibreTranslate behind a redirecting proxy is configured with its final URL.
52. The body-regex quota detection stays as in Nest for any status (rule 10): frozen, only the test-connection latency suffers (a 401 whose body says "rate limit" waits a minute).
53. The pacing buckets (rule 26) and the slot gate (rule 43) are per process, as in Nest: fine with one `fliks-server`.
