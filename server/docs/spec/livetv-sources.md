### D. M3U parser (`parseM3u`, pure; vectors)

22. Lines split on `\r?\n`, `trim()`med (JS whitespace), empty lines skipped. `#EXTM3U…` (any line starting so, the last wins): attrs via `/([A-Za-z0-9_-]+)="([^"]*)"/g`, keys lowercased, a later duplicate overwrites; `guideUrls` = `x-tvg-url || url-tvg` split on `,`, trimmed, empties dropped; `maxConnections = intOrNull(max-conn)` (`parseInt`; absent or empty → null; `"0"` → 0); `expiresAt = parseDateAttr(billed-till)`: digits only → epoch seconds when `> 1_000_000_000` else null, otherwise `Date.parse`, NaN → null. `[ts:src/modules/livetv/parsing/m3u.parser.ts:34]–[ts:src/modules/livetv/parsing/m3u.parser.ts:74]`, `[ts:src/modules/livetv/parsing/m3u.parser.ts:154]–[ts:src/modules/livetv/parsing/m3u.parser.ts:179]`
23. `#EXTINF…`: attrs parsed on the **whole line** (a `key="v"` inside the display name counts), display name = text after the **first** comma, trimmed (no comma → `''`); it starts a pending entry and resets `pendingGroup`. A line starting `#EXTGRP` sets `pendingGroup` = the text after its first `:` (trimmed, empty → null; with no `:` the whole line, e.g. `#EXTGRP`), so it only counts after its `#EXTINF`. `#EXTVLCOPT:` while an entry is pending: `http-user-agent` → userAgent, `http-referrer` or `http-referer` → referer (non-empty values only). `#KODIPROP:inputstream.adaptive.stream_headers=<qs>`: `&`-separated `k=v`, `k` lowercased, value `decodeURIComponent` (undecodable kept raw), `user-agent` and `referer|referrer` taken. Any other `#` line, and any non-`#` line without a pending entry, is ignored. `[ts:src/modules/livetv/parsing/m3u.parser.ts:180]–[ts:src/modules/livetv/parsing/m3u.parser.ts:219]`

### E. Group patterns and classification

30. `includeGroupsPattern` / `excludeGroupsPattern` are tested against the **normalised group name** (the sentinel included), case-insensitively. At save and test time an invalid regex is `BadRequestException` `<field> is not a valid regular expression: <engine message>`. At sync time an invalid saved pattern is ignored with a warn log (include: every group imports; exclude: nothing excluded). Empty string = no pattern. Patterns are free text (no default, no client preset), so stored JS patterns must keep compiling: Rust uses `fancy-regex` (already a `fliks_domain` dependency, as for the adult pattern) with `(?i)`, which accepts look-around and back-references; its backtrack limit replaces Node's unbounded backtracking: a match that hits it counts as an invalid pattern for that sync (ignored with a warn; a test answers `ok:false`), and a pattern `fancy-regex` rejects is 400 at save and test, ignored with a warn at sync, as an invalid one is today (C79).
