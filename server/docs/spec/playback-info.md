## Rules

### Playback-info: request parsing

1. Query parsing in the controller: `burnInSubtitleId` = `parseInt(first value,10)` when the string is non-empty, else `undefined`; `startAt` = `parseFloat(v)` when the query key is present (including `''`), else `undefined`; `download` is `true` only for the exact string `'1'`; `audioStreamIndex` and `startQuality` are passed as the raw first string value; "first value" = the string, or the first element when the key repeats. A non-numeric `startAt` yields `NaN` (not rejected; serialised `null` into the engine request and the presence). `[ts:src/modules/streaming/streaming.controller.ts:36-44]` `[ts:src/modules/streaming/streaming.controller.ts:130-146]`
2. `tokenParam` = `'?' + parts.join('&')` over the keys `token` then `sid` (only those present and non-empty), each `key=encodeURIComponent(firstValue)`; `''` when none. It is carried into the URLs the engine builds. `[ts:src/modules/streaming/streaming.controller.ts:47-54]`
3. `sseConnectionId` = header `x-fliks-sse-connection` or `null`; `userAgent` = header `user-agent` or `null`. `[ts:src/modules/streaming/streaming.controller.ts:143-144]`

### Playback-info: the 15 steps (numbering is this spec's; order is the code's)

4. **Step 1 gateway guard.** `engine.gatewayMismatch` (saved engine URL differs from `FLIKS_ENGINE_URL`) -> 503 `The saved engine URL is not the one this process forwards video to`. Evaluated before anything else. `[ts:src/modules/streaming/services/engine-playback.service.ts:93-97]` `[ts:src/modules/engine/engine.service.ts:190-192]`
5. **Step 2 runtime guard.** `!engine.runtime` (no adopted engine with features `sessions`,`serve`,`events`) -> 503 `The streaming engine is unreachable` when `engine.status === 'down'`, else 503 `Playback needs the streaming engine, which is not running`. `[ts:src/modules/streaming/services/engine-playback.service.ts:98-107]` `[ts:src/modules/engine/engine.service.ts:97]` `[ts:src/modules/engine/engine.service.ts:175-188]`
6. **Step 3 resolve file** (rules 38-39). 404 propagates. `info = mediaFile.streamInfo` (jsonb, may be null). `[ts:src/modules/streaming/services/engine-playback.service.ts:108-109]`
7. **Step 4 burn-in.** `burnInSubtitleId` falsy (0, NaN, absent) -> no burn-in. Otherwise `SubtitleBurnInService.resolve` then `buildFilter`; **any** throw (404 subtitle, file missing, DB) is logged `warn` and the playback proceeds without burn-in (never an error response). Result `{filter: string|null, streamIndex?, type:'text'|'image'}`. `[ts:src/modules/streaming/services/engine-playback.service.ts:289-307]` Resolve and filter rules: 42-44.
8. **Step 5 hardware.** `await hardware.apply(await settingsCache.get())` on every call (rule 47). A rejection of `settingsCache.get()` (DB) is not caught -> 500. `[ts:src/modules/streaming/services/engine-playback.service.ts:111]`
9. **Step 6 scan lookup.** `sourceScans.lookup(mediaFileId, absolutePath, info)` -> `{scan: SourceScan|null, version: string|null}` (rule 48). Never throws. It may mutate `info.timestampBreakSeconds` in place and update the DB row. `[ts:src/modules/streaming/services/engine-playback.service.ts:113-117]`
10. **Step 7 start position.** `position = startAt` when `startAt !== undefined` (so `0` restarts, `NaN` passes through); else `getState(userId, mediaFile.mediaId, episodeId)` and, when a row exists, `!completed` and `positionSeconds > 10`, use its `positionSeconds`; else `0`. `episodeId = mediaFile.episodeId ?? undefined`. DB errors -> 500. `[ts:src/modules/streaming/services/engine-playback.service.ts:118-125]` `[ts:src/modules/streaming/playback-info.util.ts:39-54]`
11. **Step 8 subtitle renditions.** Only when `device.supportsHlsSubtitles` is truthy: `listTextSubtitleRenditions(mediaFileId, user)` (rule 45); any failure -> `undefined` (swallowed, silently). `[ts:src/modules/streaming/services/engine-playback.service.ts:126-130]`
12. **Step 9 attribution, tags, client.** `attributionTarget = events.targetIdFor(sseConnectionId)`; `attributedUserId = events.takeAttribution(attributionTarget, mediaFileId)` (consumes the claim; claim valid 60 s and only for the same file id: `[ts:src/modules/scheduler/events.service.ts:371]` `[ts:src/modules/scheduler/events.service.ts:522-539]`). `tags` = string map of `{username, mediaTitle, mediaType, posterUrl, fanartUrl, sseConnectionId, attributedUserId}` with every `null`/`undefined`/`''` entry dropped and values `String()`-ed (`username` = `user.username`; media fields from `resolved.media`). `client = {deviceName, systemName, appVersion (from the DTO), userAgent: header ?? undefined}`. `[ts:src/modules/streaming/services/engine-playback.service.ts:131-151]` `[ts:src/modules/streaming/services/engine-presence.ts:26-32]`
13. **Step 10 open.** `engine.openSession(OpenSessionRequest)` = `POST /v1/sessions` with body:
    `{ decide: { media: {mediaFileId, path: absolutePath, ext, contentType}, info, scan: held.scan, device: <DTO as received after whitelist>, selection: { tokenParam, burnInSubtitleId: burnIn ? q.burnInSubtitleId : undefined, burnInIsText: !!burnIn?.filter, requestedQuality: q.startQuality, audioStreamIndex: resolveAudioStreamIndex(q.audioStreamIndex, info?.audio?.length ?? 0) } }, ownerId: String(user.id), client, tags, startAtS: position, pinned: q.download, burnIn: burnIn && {type, filter: filter ?? undefined, streamIndex}, sourceVersion: held.version ?? undefined, subtitleRenditions }`.
    `resolveAudioStreamIndex`: `Number(raw)` must be an integer in `[0, audioCount)`, else `undefined` (first track). The engine client retries 503 + `Retry-After` (default 1 s) until 15 s elapse, then throws `EngineError(503)`. `[ts:src/modules/streaming/services/engine-playback.service.ts:153-195]` `[ts:src/modules/streaming/playback-info.util.ts:4-13]` `[ts:src/modules/engine/engine.service.ts:98]` `[ts:src/modules/engine/engine.service.ts:562-576]`
14. **Open error mapping.** `EngineError` with status 400 -> 400 `BadRequestException(err.message)` where `err.message` = `POST /v1/sessions -> 400`; any `HttpException` rethrown as is; every other error -> warn log + 503 `The streaming engine is unavailable`. On any failure, when `attributionTarget` and `attributedUserId != null`, the claim is given back (`claimAttribution(target, userId, mediaFileId)`) before rethrowing. `[ts:src/modules/streaming/services/engine-playback.service.ts:187-195]` `[ts:src/modules/streaming/services/engine-playback.service.ts:274-286]` `[ts:src/modules/engine/engine.service.ts:64-73]`
15. **Step 11 presence.** `kind = 'directplay'` if `response.playMethod === 'DirectPlay'`, `'remux'` if `'DirectStream'`, else `'transcode'`. `liveSessions.create(presenceInput(...))` keyed by the engine `sessionId`, with `position`, `quality = q.startQuality ?? null` (the *requested* quality, not the engine's), `profileHash = open.profileHash ?? null`, fields per `presenceInput` (`deviceLabel = client.userAgent ?? null`, `bitrateByQuality = response.transcodeBitrateByQuality ?? null`, `hdrLadder = decision.useHdrLadder`, `clientTonemap`, `transcodeReasons`, `audioPlan`, `sourceFps = parseSourceFps(response.source.frameRate)`, `attributedUserId` = `Number(tags.attributedUserId)` if integer else null). New presence: `state:'playing'`, `startedAt = lastBeat = now`, defaults per `buildLiveSession`. `[ts:src/modules/streaming/services/engine-playback.service.ts:199-218]` `[ts:src/modules/streaming/services/engine-presence.ts:72-100]` `[ts:src/modules/streaming/live-session.service.ts:123-166]`
16. **Step 12 QoE.** `qoe.register(live)`; if `open.qoePipeline` is present, `qoe.setPipeline(live, toQoePipeline(open.qoePipeline))` where absent members become explicit `null` (`source, decode, encode, tonemap, burnIn, crop, audioTranscode` default `null`; `output` null or its five fields defaulted to `null`). `[ts:src/modules/streaming/services/engine-playback.service.ts:220-222]` `[ts:src/modules/streaming/services/engine-presence.ts:35-56]`
17. **Step 13 rescan hint** (fire and forget, `void`, never awaited, never affects the response): `open.hints.probeStale` -> `staleProbeRescan.schedule(mediaFileId, absolutePath)`; else `open.hints.scanMissing` -> `sourceScans.scheduleIfNeeded(mediaFileId, absolutePath, info, 'high')`. `[ts:src/modules/streaming/services/engine-playback.service.ts:224]` `[ts:src/modules/streaming/services/engine-playback.service.ts:309-326]`
18. **Step 14 extras in parallel** (`Promise.all`, started in this order): markers (rule 19), pre-roll (rule 20), EDL sidecar (rule 21), `markSessionStarted` (rule 22). `fps = parseSourceFps(info.video[0].frameRate)` (decimal or `a/b` rational; `undefined` when unknown). **Failure isolation:** only the markers query can reject (the other three never reject: pre-roll `ask` swallows plugin failures, EDL read returns `null`, `markSessionStarted` is `.catch`-ed with a `warn`); a markers DB error therefore yields 500 **after** the engine session was opened and presence + QoE tracker were created (no rollback; the engine reaps the session by TTL). `[ts:src/modules/streaming/services/engine-playback.service.ts:225-255]`
19. **Markers.** Only when `episodeId` is truthy (movies: `undefined`). Two reads, concurrent: `findIntroForEpisode`, `findOutroForEpisode` (SQL below). Result `{ intro: {startSeconds,endSeconds}|undefined, outro: ... }` only if at least one exists, else `undefined`; an absent side is `undefined`, i.e. the key is omitted in JSON. `recap` markers are never read here. `[ts:src/modules/streaming/services/engine-playback.service.ts:328-341]` `[ts:src/modules/markers/markers.service.ts:58-68]`
20. **Pre-roll.** `PluginPreRollService.ask({mediaFileId, mediaId, episodeId, principal:{kind:'delegated', userId}})` (bridge until S8, see Bridges). Never throws: no declaring plugin, plugin failure/timeout, non-200 or malformed body all answer `[]`; items are sanitised (positive integer `mediaFileId`, not the main file, no repeats, at most `PRE_ROLL_ITEMS_MAX`, optional `labelKey:string`, `skippable:boolean`). Then each candidate id is re-checked with `streamingService.resolveFile(id, user)` via `Promise.allSettled`; only fulfilled candidates stay. Result `undefined` (key omitted) when empty, never `[]`. `[ts:src/modules/streaming/playback-info.util.ts:15-32]` `[ts:src/modules/plugins/plugin-pre-roll.service.ts:28-82]` `[ts:src/modules/streaming/services/engine-playback.service.ts:228-239]`
21. **EDL.** Skipped (`undefined`) when `user.edlEnabled === false`; else `readEdlSidecar(absolutePath, fps)` (rules 40-41). In the response, `edl` = `shiftRanges(edl, open.playbackClockOffsetS ?? 0)` when the read yields a non-empty array, else key omitted. `[ts:src/modules/streaming/services/engine-playback.service.ts:240-242]` `[ts:src/modules/streaming/services/engine-playback.service.ts:260-262]`
22. **markSessionStarted** runs only when `!q.download && user.id && mediaFile.mediaId`: ensures a `playback_states` row exists and bumps `lastPlayedAt` (SQL below); never sets `playedAt`; the failure is swallowed with a warn. For an existing row the `state.mediaFileId = mediaFileId` assignment is a no-op (a `@RelationId` virtual is not persisted), so the linked file only changes at the next heartbeat write. A download (`download=1`) never touches history. `[ts:src/modules/streaming/services/engine-playback.service.ts:243-254]` `[ts:src/modules/playback/playback.service.ts:295-319]`
23. **Step 15 response** = `{ ...engine.decision.response, playUrl: open.playPath, edl, tonemapAlgo: open.tonemapAlgo ?? null, tonemapCurve: open.tonemapCurve ?? undefined, durationSeconds: info?.durationSeconds ?? 0, markers, chapters: info?.chapters?.length ? info.chapters : undefined, preRoll, sessionId: open.sessionId, profileHash: open.profileHash ?? null }`, JSON-serialised (undefined keys omitted; `tonemapAlgo` and `profileHash` always present, `null` when unknown). `playUrl` carries the sid (`/api/stream/<id>/master.m3u8?sid=<sid>`) so it overrides `response.playUrl`. All other fields come from the engine decision and are frozen by the golden (`mediaFileId, playMethod, contentType, transcodeReasons[{flag,message}], videoCopyStream, audioCopyStream, outputVideoCodec, outputAudioCodec, audioPlan, outputContainer, quality, hwAccel, tonemapping, clientTonemap, dolbyVision, transcodeBitrateByQuality, remuxMasterBandwidthBps, qualities[QualityOption], audioTracks[AudioTrackPlan], source{...}`; shape = `PlaybackInfoResponse`). `[ts:src/modules/streaming/services/engine-playback.service.ts:257-271]` `[ts:src/modules/streaming/dto/playback-info.dto.ts:76-216]`
23a. **Track markers** (additive after 5.0.0, #1763; `fliks_domain::track_markers`). Each `audioTracks[]` entry gains `trackMarkers` (string array, always present) and `title` (the source stream's title, absent when it has none), read from `info.audio[index]`; an index outside `info.audio` gives `trackMarkers: []` and no `title`. The same `trackMarkers` is added to every `streamInfo.audio[]`/`subtitles[]` entry of the media JSON (`media-query.md` rule 30). Derived at read time, in this order, from the stored stream:
    - audio: `hearingImpaired`, `commentary` (flag or title), `audioDescription` (flag or title), `original`, `dub`, `musicAndEffects` (`cleanEffects`), `karaoke`, `atmos` (`profile` contains `atmos`), `dtsX` (`profile` contains `dts:x`), case-insensitive;
    - subtitles: `forced` (flag, or title unless `non`/`not forced`), `hearingImpaired` (flag or title), `commentary` (flag or title), `descriptions`, `lyrics`;
    - titles match whole words, case-insensitive: commentary `commentary`, `commentaries`, `commentaire(s)`; audio description `audio description`/`audiodescription`/`audio described`, `description audio`, `AD`, `malvoyant(s)`; SDH `sdh`, `cc`, `sme`, `hearing impaired`, `closed caption(s)`, `sourds`, `malentendants`; forced `forced`, `forcé(s)`. A title only adds a marker, it never drops a track.
    The flags are the engine probe's (`schemaVersion` 2 added `hearingImpaired`, `original`, `dub`, `cleanEffects`, `karaoke` on audio, `commentary`, `descriptions`, `lyrics` on subtitles). An older blob has none of them until it is re-probed: the engine hints `probeStale` for it (rule 17), so its next playback re-probes it (rule 51); titles and profiles are already stored, so their markers show at once.
24. The host decides nothing about play method, quality ladder or tonemap: those come from the engine's `decision.response`; the Rust port must not recompute them. `[ts:src/modules/streaming/services/engine-playback.service.ts:64-65]`
