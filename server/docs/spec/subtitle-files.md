# Spec: subtitle-files (sidecar paths, writing, post-processing, cleaning, OCR/sync jobs)

Sources: `[ts:src/modules/subtitles/subtitles.service.ts]`, `[ts:src/modules/subtitles/subtitle-path.util.ts]`, `[ts:src/common/utils/media-path.util.ts]`, `[ts:src/modules/subtitles/subtitle-matching.ts]`, `[ts:src/modules/subtitles/subtitle-cleaner.ts]`, `[ts:src/modules/subtitles/subtitle-post-processor.ts]`, `[ts:src/modules/subtitles/subtitle-sync.service.ts]`, `[ts:src/modules/subtitles/subtitle-ocr.service.ts]`, `[ts:src/modules/subtitles/embedded-subtitle.service.ts]`, `[ts:src/modules/subtitles/moviehash.ts]`, `[ts:src/common/constants/subtitle-flags.ts]`, `[ts:src/common/constants/subtitle-codecs.ts]`, `[ts:src/common/constants/app-languages.ts]`. Engine contract: `[engine:docs/spec/subtitle-jobs.md]`, `[engine:PROTOCOL.md]`. Milestone: S6. Tag paths are relative to `backend/`.

Companion of `subtitles.md` (routes, search, score, scheduler; cited "subtitles rule N"). Path model: `M` = `Media.path` (library path joined with `folderName`, or the library path for a root-level movie), `Mc` = `realpath(M)`; `within(M, p)` is the containment predicate of `ingest.md` rule 5 applied to `M` (deepest existing ancestor resolved with `realpath`, must have `Mc` as ancestor). Plan §0 rule 10: every write below is exercised only on generated media under `/tmp/fliks-parity/`; no test, parity run or agent points a write at real media.

This spec has no HTTP routes of its own: the routes that reach these rules are in `subtitles.md` (`upload`, `download`, `auto`, `post-process`, `sync`, `ocr`, `delete`). Writes of this module (inventory, every site that touches the disk):

## Rules

### A. Names, languages, path helpers

1. Sidecar name = `<video basename without extension>.<suffix><ext>` in the video file's own directory (`path.parse(path.join(M, mediaFile.relativePath))`); `ext` is `.srt` for a provider download, the lowercased upload extension for an upload (`.srt .ass .ssa .vtt .sub .sup`), `.ocr.srt` for OCR. A row's `relativePath` is relative to `M`, `/`-separated (readers normalise `\` to `/`), stored in the column `filePath`. `[ts:src/modules/subtitles/subtitles.service.ts:256]`–`[ts:src/modules/subtitles/subtitles.service.ts:307]`
2. `sidecarLangSuffix(lang, forced, hearingImpaired)` = `lang + '.forced'` when forced (wins over HI), else `lang + '.hi'` when HI, else `lang`. Vector set `subtitles` (`subtitle-lang-suffix.spec.ts`). `[ts:src/modules/subtitles/subtitles.service.ts:63]`
3. `normalizeLanguageCode(x)`: `(x ?? '').trim().toLowerCase()` split on `-` or `_`; empty primary → `und`; `FOLDED_CODES[primary-second]` (macro-language folds) wins; else ISO 639-2 to 639-1 (`ISO_639_2_TO_1_FULL`, unknown stays), then `FOLDED_CODES[iso1] ?? iso1`. It passes an unknown tag through unchanged (`x/..` stays), so `assertSafeLangSuffix(suffix)` requires `^[a-z]{2,3}(\.(forced|hi))?$` before any name is built (400 `Invalid subtitle language "<suffix>"`). The tables (`APP_LANGUAGES`, `ISO_639_2_TO_1_FULL` from `common/constants/iso-639-2.ts`, `FOLDED_CODES`) move to `fliks_domain` as data; vector `subtitles`. `[ts:src/common/constants/app-languages.ts:91]`, `[ts:src/modules/subtitles/subtitle-path.util.ts:35]`
4. `resolveSubtitleAbsolutePath(root, stored)`: `null` when `stored` or `root` is blank (after `trim()`); `abs = path.resolve(path.resolve(root), stored.trim())` (an absolute `stored` replaces the root); `null` unless `abs` equals the root or starts with `root + sep`. Purely lexical: `..` is collapsed, symlinks are followed by every later `open`/`unlink`/`rename`. `relativePathUnderMediaRoot(root, file)`: `rel = relative(resolve(root.trim()), resolve(file))` with `\` → `/`; `null` when `rel` is empty, starts with `..` (also refuses a legitimate name such as `..foo`) or is absolute. Both are vectors (`subtitle-path.util.spec.ts`). `[ts:src/modules/subtitles/subtitle-path.util.ts:9]`, `[ts:src/common/utils/media-path.util.ts:7]`
5. `resolveMediaFilePath(mediaId, mediaFileId, episodeId?)`: media missing → 404 `Media #<id> not found`; `media.path` null → 400 `Assign a root folder to this media before downloading subtitles`; media file missing, of another media, or (when `episodeId` is given) of another episode → 404 `MediaFile #<id> not found`; returns the lexical `join(M, relativePath)`. A `mediaFileId` of `undefined` makes TypeORM `findOne({where: {id: undefined}})` return the first row of the table; the `mediaId` comparison then rejects it (Rust: 400 on a missing id, C?4). `[ts:src/modules/subtitles/subtitles.service.ts:491]`–`[ts:src/modules/subtitles/subtitles.service.ts:516]`

### B. Writing a sidecar (SW1)

6. `writeSidecar(mediaId, videoAbs, suffix, ext, buffer)` in this order: (1) `assertSafeLangSuffix(suffix)` (400); (2) reload the media with its library, `path` null → 400 `Assign a root folder to this media before adding subtitles`; (3) `candidate = join(dirname(videoAbs), name + '.' + suffix + ext)`; while `fs.access(candidate)` succeeds (a symlink is followed: a dangling one reads as free) the suffix becomes `<suffix>-1`, `-2`, … without limit; (4) `relativePathUnderMediaRoot(M, candidate)` null → 400 `Subtitle file would be outside the media folder; check root folder configuration` (nothing written yet); (5) `mkdir -p dirname(candidate)`; (6) `writeFile(candidate, buffer)` (follows symlinks, overwrites if the name appeared since step 3, no `fsync`, no temp file); (7) returns the relative path. The row insert is the caller's; a failed insert leaves the file on disk. `[ts:src/modules/subtitles/subtitles.service.ts:256]`–`[ts:src/modules/subtitles/subtitles.service.ts:307]`
7. [new] F?1 (security): every sidecar create, rewrite, rename and unlink (SW1-SW5) is confined to the media directory by a symlink-safe check; Nest's check is lexical, so a symlinked subdirectory or a symlinked sidecar inside `M` redirects the write, truncation or deletion to any path the server can reach (`writeFile` on a dangling symlink creates its target). Rust: (a) the target's parent directory is resolved with `realpath` and must satisfy `within(M, parent)` (strict descendant of `Mc` or `Mc` itself for a root-level movie, `ingest.md` rule 5), re-checked immediately before the destructive call; (b) a create uses `open(O_CREAT|O_EXCL|O_NOFOLLOW)` in the `-N` loop (no `access` then write race, no overwrite), a rewrite or unlink first `lstat`s the final component and refuses anything that is not a regular file (400 `Subtitle path is not a regular file`) or whose realpath leaves `Mc`; (c) **no directory is created** by a sidecar write (SW6 is deleted: the video's directory must exist, else 404 `Media file is missing on disk`; Nest recreates the folder tree of a deleted video and drops a lone sidecar into it); (d) `relativePath` is recomputed from the realpath-checked target and must not contain `..`; (e) a row whose `relativePath` fails the check at read time is treated as unresolvable (as Nest's `null`: post-process 404 `Subtitle file path could not be resolved`, delete removes only the row, sync 400). The `-N` loop stops at 99 with 409 `Too many sidecars with this name` (Nest has no bound).
8. Upload (`uploadSubtitle`): `ext = lower(extname(originalname))` must be in `{.srt .ass .ssa .vtt .sub .sup}` (400 `Unsupported subtitle format: <ext>`); the body decoded as UTF-8 (lossy) must match `/-->|^Dialogue:/m` (400 `File holds no subtitle cues`; so a binary `.sup` or a MicroDVD `.sub` upload is always this 400); `resolveMediaFilePath` (rule 5); `lang = normalizeLanguageCode(language)` (`language` absent = `und`); flags: `forced = opts.forced ?? parsed.forced`, `hearingImpaired = (opts.hearingImpaired ?? parsed.hearingImpaired) && !(isSrt && removeHiTags)` where `parsed = parseSubtitleFilename(originalname)` (rule 9; flags from the filename only when the form field is absent); an `.srt` goes through `cleanSubtitle` with `removeAds: true`, `removeHiTags` and the custom exclusions, every other format is stored byte for byte; `writeSidecar` (rule 6); the row: `providerType: 'disk'`, `status: 'downloaded'`, `score: 100`, `synced: true`, `language`, `forced`, `hearingImpaired`, `relativePath`, the episode stub. Limit 5 MiB (`SUBTITLE_UPLOAD_MAX_BYTES`), multipart field `file`, over the limit 413 `file_info.import_err_too_large`; the router body limit override applies to this route only (plan §3.1). `[ts:src/modules/subtitles/subtitles.service.ts:421]`–`[ts:src/modules/subtitles/subtitles.service.ts:485]`

### C. Filenames, discovery, reconcile

9. `parseSubtitleFilename(filename)` (vector `subtitle-filename.spec.ts`): `null` unless `lower(extname)` is in `{.srt .ass .ssa .vtt .sub .sup}`; `parts = name-without-extension.split('.')`; scan `i` from the last part down to index 1 (part 0 is the video name and is never read), `token = lower(parts[i])`: `forced`/`foreign` → `forced = true`; `hi`/`cc`/`sdh` → a lone `hi` while no language is found yet is the language Hindi (`language = 'hi'`, remembered as `hiCandidate = i`), any other HI token (or `hi` once a language exists) → `hearingImpaired = true`, `hiPart = i`; `default`/`ocr` ignored; a token `resolveLanguageCode` knows → `language` (and a pending `hiCandidate` becomes the HI flag: `Movie.en.hi.srt`); any other token stops the scan. Result `{language ('und' default), forced, hearingImpaired, hiPart: number|null}`. `[ts:src/modules/subtitles/subtitles.service.ts:661]`–`[ts:src/modules/subtitles/subtitles.service.ts:711]`
10. `resolveLanguageCode(token)` in order: 2 letters `[a-z]{2}` present in the `APP_LANGUAGES` iso codes; culture form `^([a-z]{2})-[a-z]{2,}$` (case-insensitive) → the first part, **not** checked against the known list; ISO 639-2 3-letter map `ISO_639_2_TO_1` (built from `APP_LANGUAGES[].iso639_2`, narrower than rule 3's `ISO_639_2_TO_1_FULL`); full lowercase language name from `APP_LANGUAGES` (excluding iso `xx`; a multi-word name cannot match because the name is split on `.` first); else `null`. `[ts:src/modules/subtitles/subtitles.service.ts:731]`–`[ts:src/modules/subtitles/subtitles.service.ts:744]`
11. `stripHiFromFilename(name)`: `null` when the name does not parse or has no `hiPart`; else the name with that dot-part removed (extension kept as written). A rescan re-derives the HI flag from the name, hence the rename when HI cues are removed (rule 15, `removeHiTags`). `[ts:src/modules/subtitles/subtitles.service.ts:717]`–`[ts:src/modules/subtitles/subtitles.service.ts:724]`
12. `matchSubtitleVideo(entry, dir, files, mediaPath, hasOwnFolder)` (also used by the companion listing, `media-write.md`): map lower-cased video basenames (last file wins on a duplicate base) to files; for `len = parts-1 .. 1` of the sidecar's lower-cased basename split on `.` (`path.basename(entry, lower(ext))` strips the extension only when it is written lower-case, so `X.EN.SRT` keeps `srt` as a last part), the first dot-prefix equal to a video base wins (longest prefix first); no hit and the media has no own folder (`folderName` empty) → `null`; else the files whose directory equals `dir`: exactly one → it; none and the media has exactly one file → that file; else `null`. Vector set `subtitles` (`matchSubtitleVideo`, no existing spec: write one from this rule). `[ts:src/modules/subtitles/subtitle-matching.ts:7]`–`[ts:src/modules/subtitles/subtitle-matching.ts:30]`
13. `discoverExternalSubtitles(mediaId)` (rescan, S5 caller): media with files; no `M` or no files → `0`. Directories scanned = `M` plus the directory of every media file (non-recursive `readdir`; an unreadable directory is skipped). Per entry: extension in `{.srt .ass .ssa .vtt .sub .sup}`; renderable only (`.srt .ass .ssa .vtt`, or an image sidecar: `.sup` = `hdmv_pgs_subtitle`, `.sub` with a same-named `.idx` in the same listing, case-sensitive = `dvd_subtitle`); relative path (`path.relative(M, abs)`, `\` → `/`) not already a row of this media; `matchSubtitleVideo`; `parseSubtitleFilename`. Insert `{media, mediaFile: matched, episode: matched.episodeId, language, codec: imageCodec (null for text), forced, hearingImpaired, providerType: 'disk', relativePath, status: 'downloaded', score: 100, synced: true}`; returns the number inserted. Nest `lstat`s nothing: a symlink or a directory named `x.srt` becomes a row, and the file-serving side (engine resolver `purpose: subtitle`, `[engine:PROTOCOL.md:49]`) then reads whatever it points to. [new] F?1: entries must be regular files (`lstat`, symlinks and directories skipped, same filter as the companion listing) and their realpath within `Mc`. `[ts:src/modules/subtitles/subtitles.service.ts:754]`–`[ts:src/modules/subtitles/subtitles.service.ts:843]`
14. `reconcileSubtitleFilesAfterRescan(mediaId)` returns `{removedMissing, removedDuplicates}` (both in the `rescan.completed` event, `events-hub.md` row 18). External = not `embedded`, not `processing`, not `failed` (those are state, not stale sidecars). (1) Every external row with a blank `relativePath` or whose `resolveSubtitleAbsolutePath(...)` is `null` or does not exist (`existsSync`, follows symlinks) is deleted. (2) Rows left, grouped by normalised `relativePath`; per group of two or more the winner is the locked row, else the higher `score`, else the higher `id`; the others are deleted (rows only, never a file). Same-language sidecars of different names are never collapsed. Rust: existence via `lstat` + realpath check (rule 7). `[ts:src/modules/subtitles/subtitles.service.ts:567]`–`[ts:src/modules/subtitles/subtitles.service.ts:630]`

### D. Post-processing (SW3, SW4)

15. `POST /post-process {action, params?}`: row by id (404); no `relativePath` → 400 `Subtitle has no file path`; unresolvable → 404 `Subtitle file path could not be resolved`; the file is read whole as UTF-8 (no size limit, no format check: a `.sup`/`.sub` is mangled by the UTF-8 round trip) **before** the action is validated, so an unknown action on a missing file is a read error (500 `ENOENT`) rather than 400. Actions (`switch`), each a pure `string → string` function (vectors `subtitle-post-processor.spec.ts`): `removeHiTags` = `cleanSubtitle` with `removeAds: false, removeHiTags: true`; `removeStyleTags`; `removeEmoji`; `ocrFixes`; `commonFixes(content, row.language)`; `fixUppercase`; `reverseRtl`; `adjustTimes` with `offsetMs = Number(params.offsetMs ?? 0)`; `changeFrameRate` with `fromFps = Number(params.fromFps ?? 23.976)`, `toFps = Number(params.toFps ?? 25)`; `convertToSrt`; anything else 400 `Unknown post-processing action: <action>`. Then `writeFile(abs, content)` (truncating, in place), `removeHiTags` on a row with `hearingImpaired` → `dropHiTag`, `convertToSrt` with changed content → rename (rule 17); `locked = true` always, even when the content did not change; `save(row)`; response = the row `SF`. `[ts:src/modules/subtitles/subtitles.service.ts:1011]`–`[ts:src/modules/subtitles/subtitles.service.ts:1109]`
16. Pure functions (the `subtitles` vector set; regexes are JS and must be ported with their semantics, see rule 36): `removeStyleTags` = `/<\/?[a-z][^>]*>/gi` then `/\{\\[^}]+\}/g` removed; `removeEmoji` = remove the code points `1F600-1F64F 1F300-1F5FF 1F680-1F6FF 1F1E0-1F1FF 2600-26FF 2700-27BF FE00-FE0F 1F900-1F9FF 1FA00-1FA6F 1FA70-1FAFF 200D 20E3`; `fixOcr` = the ten ordered replacements `\bl\b(?=[A-Z])→I`, `\bln\b→In`, `\bIVIr\b→Mr`, `\bIVIrs\b→Mrs`, `\brn(?=[aeiou])→m`, `\b0(?=[a-zA-Z])→O`, `(?<=[a-zA-Z])0\b→O`, `\|\|→H`, `\|(?=[a-z])→l`, `\|(?=[A-Z])→I`; `commonFixes` = `  +`→space, `\. \.`→`..`, `....`→`...`, ` +([,.])`→`$1` for `fr` (space before `? ! ; :` is French typography) else ` +([,.!?;:])`→`$1`, `([.!?])\1{3,}`→three, whitespace-only lines emptied (`^[ \t]+(?=\r?$)` multiline), leading blank lines removed, `(\r?\n){3,}`→`$1$1` (the last matched break, twice); `fixUppercase` = per block (split `\r?\n\r?\n`, blocks of fewer than 3 lines untouched) every text line (after index and timing) whose ASCII letters (`[a-zA-Z]`, more than one) are all upper case is lower-cased and capitalised when it starts a sentence (first text line, or the previous line ends with `.!?…` plus spaces), blocks re-joined with `\n` (CRLF is lost in processed blocks, blocks joined by a blank line); `reverseRtl` = per block, text lines containing a char in U+0590-05FF, 0600-06FF, 0700-074F are reversed (Nest by UTF-16 code unit: an astral character such as an emoji becomes two lone surrogates written as U+FFFD; Rust reverses by scalar value, `[new]`, differs only on such lines); `adjustTimes(content, offsetMs)` and `changeFrameRate(content, from, to)` rewrite only SRT timestamps `(\d{2}):(\d{2}):(\d{2}),(\d{3})` (ASS and WebVTT `.` timestamps are untouched yet the file is still rewritten and locked): total ms plus offset clamped at 0 (resp. `round(ms * from / to)`; `from <= 0`, `to <= 0` or equal returns the input), re-rendered `HH:MM:SS,mmm` with hours not capped; `assToSrt` (rule 17). `[ts:src/modules/subtitles/subtitle-post-processor.ts:9]`–`[ts:src/modules/subtitles/subtitle-post-processor.ts:238]`
17. `assToSrt(content)`: lines starting with `Dialogue:` (split on `\n`); none → the input unchanged; per line split on `,`, fewer than 10 fields skipped, `start = fields[1].trim()`, `end = fields[2].trim()`, text = fields 9.. rejoined with `,`, `\N` → newline, `{\...}` override tags removed, trimmed, empty skipped; times `H:MM:SS.cc` → `HH:MM:SS,cc0` (regex `^(\d+):(\d{2}):(\d{2})\.(\d{2})$`, an unparseable time is copied unchanged); blocks `<n>\n<start> --> <end>\n<text>` joined by a blank line plus a final `\n`; no block produced → the input. Dialogue order is the file order (not sorted by time). `convertToSrt` renames `<name>.<ext>` to `<name>.srt` only when the content changed (`converted !== content`); `renameSubtitleFile` refuses when the target exists and then keeps the old name **with SRT content inside** (the row's `codec` stays; C?3 refuses with 409 before writing); on success `codec = 'subrip'` and `relativePath` updated. `[ts:src/modules/subtitles/subtitle-post-processor.ts:199]`–`[ts:src/modules/subtitles/subtitle-post-processor.ts:238]`, `[ts:src/modules/subtitles/subtitles.service.ts:1075]`
18. `carryOver(mediaId, fromFileId, to: MediaFile)` (ingest, S5 caller; supersede): media without `M` or unknown source file → `[]`; for each row of the old file that is not embedded, has a path and whose basename starts with `<old base>.` (case-sensitive): `rel = join(dirname(to.relativePath), newBase + name.slice(oldBase.length))`; both ends via `resolveSubtitleAbsolutePath`; skip when either is `null` or the destination exists (`existsSync`); `rename` (failure logged, row skipped); the row gets the new `relativePath`, `mediaFile = to`, `hashMatched = false` (the hash named the old file, and a stale `true` would shield it from upgrades); saved; returns the moved ids (the ingest then runs `syncSubtitle(id, {automatic: true})` per id, `ingest.md` rule 32). Rows left behind (their target name existed) are deleted with the old file's cascade; their files are removed by `deleteSubtitleFilesOnDisk`. Rust: destination created with no-replace rename (`ingest.md` rule 12), both ends under rule 7. `[ts:src/modules/subtitles/subtitles.service.ts:862]`–`[ts:src/modules/subtitles/subtitles.service.ts:895]`
19. `deleteSubtitleFilesOnDisk(mediaId, mediaFileId)` (media file delete, S5 caller): media without `M` → return; rows of the media; a `keep` set holds the normalised `relativePath` of every row belonging to **another** file; for each row of this file that is not embedded and has a path and is not in `keep`: resolve (lexical) and `unlink` (a missing file counts as removed; any other error is logged `WARN`, the delete continues). Rows go with the `media_files` cascade. `[ts:src/modules/subtitles/subtitles.service.ts:898]`–`[ts:src/modules/subtitles/subtitles.service.ts:930]`
20. `deleteSubtitle(id)` (route, and companion delete of a tracked sidecar, `media-write.md` rule 93): row missing 404 `SubtitleFile #<id> not found`; embedded 400 `Cannot delete an embedded subtitle`; the file is unlinked when the path resolves (a failure is logged, **the row is deleted anyway**), then the row. Unlike rule 19 it does not check whether another row (another version of the movie) still lists the same file, so deleting one row removes a sidecar shared through the companion scheme (C?8: skip the unlink while another row lists the same `relativePath`). A `processing` OCR/translation row has no path: only the row goes, and the running job later writes its file with nothing to attach it to (C?2: the run checks the placeholder still exists before writing). `[ts:src/modules/subtitles/subtitles.service.ts:845]`–`[ts:src/modules/subtitles/subtitles.service.ts:856]`
21. `renameSubtitleFile(row, abs, newName)`: target = `join(dirname(abs), newName)`; equal to `abs` → ok; target exists (`access`) → warn and refuse (`null`, the caller keeps the old name and the old metadata); `rename` error → warn, `null`; success updates `relativePath` = `join(dirname(relativePath), newName)` with `\` → `/`. `dropHiTag`: no HI token in the name → only the flag is cleared (`hearingImpaired = false`, no rename); a token and a successful rename → the flag is cleared; a refused rename keeps the flag. `[ts:src/modules/subtitles/subtitles.service.ts:1112]`–`[ts:src/modules/subtitles/subtitles.service.ts:1162]`

### E. Sync job (SW3)

22. `doSync(id, options)` (queue and `syncSubtitle`): row missing 404; embedded 400 `Cannot sync an embedded subtitle`; the media file (404 `MediaFile #<id> not found`) must have `streamInfo` (else `Error('No probe data for this file; rescan the media first')`); the media needs `M` (404 `Media #<id> not found or has no root path`); `subPath = resolveSubtitleAbsolutePath(M, relativePath)` null → 400 `Subtitle has no resolvable file path (check media root folder and relative path)`; `format = lower(extname)` in `srt sub ass ssa vtt` else 400 `Cannot sync a .<ext> subtitle` (a `.sup` row fails here); the sidecar read as UTF-8; `reference` = rule 23; `syncFailed = false`, `errorMessage = null` on the in-memory row. Engine job: `runJob({kind: {type: 'SubtitleSync', info: mediaFile.streamInfo, subtitle: {format, text}, reference, maxOffsetSeconds, noFixFramerate, gss: goldenSectionSearch}, media: {mediaFileId, path: join(M, mediaFile.relativePath)}, priority: automatic ? 'low' : 'high'})` (engine-glue rules 30-33, no timeout on the wait). Success: `writeFile(subPath, result.subtitle.text)` (in place), `synced = true`, `status = 'synced'`, save; side effects SSE `subtitle.synced {subtitleId, language, mediaId, automatic}`, notification `subtitle.synced {language, subtitleId}`, media-server dispatch `subtitle.synced {title, path: M}`. Failure of the job or the write: `syncFailed = true`, `errorMessage = detail.slice(0, 2000)`, row saved, throws `Error('Sync failed: <detail>')` (the queue item records it). A throw before the engine call (read error, `format`, `reference`) records nothing on the row. The row's `score`, `locked` (set at enqueue) and `syncOffset` are not touched; `syncOffset` is never written by any code (always null). `[ts:src/modules/subtitles/subtitle-sync.service.ts:187]`–`[ts:src/modules/subtitles/subtitle-sync.service.ts:292]`

### G. Cleaner (vector `subtitle-cleaner.spec.ts`)

30. `cleanSubtitle(buffer, {removeAds = true, removeHiTags = false, customExclusions = []})`: decode UTF-8 (lossy); split into blocks on `\r?\n\r?\n`; a block of fewer than 2 lines is kept as a raw block when non-blank; otherwise `header` = the first two lines (index, timing; **assumed**, a block without an index line takes its first text line as timing) and `text` = the rest; with `removeAds` the block is dropped when `AD_PATTERNS` (rule 31) match the text lines joined with a space; then dropped when any custom exclusion matches (rule 33); survivors keep `header` and the text joined with `\n`. With `removeHiTags` rule 32 runs. Finally blocks whose text is empty after `trim()` are dropped, the numeric indexes renumbered from 1 (only a header line matching `^\d+$` after `trim()`, which also strips a leading BOM; a non-numeric first header line is kept and does not consume a number), blocks joined by a blank line and one final `\n`. Line endings inside kept blocks become `\n`. `[ts:src/modules/subtitles/subtitle-cleaner.ts:146]`–`[ts:src/modules/subtitles/subtitle-cleaner.ts:229]`
31. `AD_PATTERNS` (case-insensitive, tested on the joined text): `opensubtitles`, `subscene`, `addic7ed`, `sub(s|title)?\s*(by|from|ripped|downloaded)`, `sync(ed|hronized)?\s*(by|&|and)\s`, `www\.\S+\.\S+`, `https?://\S+`, `support\s+us\s+and\s+become`, `advertise\s+your\s+product`, `a]?]?[a-z]*sub[a-z]*\.(com|org|net|io)` (the stray `]?]?` is literal in the source regex and is ported as written), `please\s+rate\s+this\s+subtitle`, `captioning\s+sponsored\s+by`, `captions\s+(by|copyright|paid)`. 32. HI removal (`removeHiTags`): per kept cue (raw blocks untouched): (1) remove spans `[...]`, `(...)`, `（...）`, `［...］` of 1-300 chars, across line breaks, only when the inside, trimmed, has at least 2 chars and one letter or digit (`(?)` and `(12)` stay); remove the symbols U+266A-266F, U+00B6, U+1F3B5, U+1F3B6, U+1F4F1, U+260E, U+260F, U+27A1, U+21D2; (2) `recurringNameLabels`: labels `^([ \t]*)((?:[-–—][ \t]*)?)([^\n:]{1,30}):(?=[ \t]|$)` (`gm`) per line (label 1-30 chars without `:` or newline) that look like a name (`^\p{Lu}[\p{L}'’.\-]*( \p{Lu}...){0,2}$`) and occur at least twice over the stripped text; (3) `stripLabels`: an all-caps label (at least 2 capital letters, no lower case) or a recurring name label is removed (the dash prefix and indent stay); (4) when the share of fully upper-case text lines (lines with a letter and no lower case; raw blocks are counted too, as in (2)) is below 0.7, drop lines that are all caps with at least 4 letters, no `!` or `?`, and match the English cue vocabulary `HI_CAPS_CUE` (`LAUGH CHUCKL GIGGL APPLAU CLAP CHEER MUSIC SONG SINGING PLAYING THEME SIGH GASP GRUNT GROAN MOAN PANT SCREAM SHOUT YELL WHISPER MUMBL MUTTER SOB SNIFF COUGH SNORE KNOCK DOOR BELL PHONE RING BEEP BUZZ SIREN ALARM GUNSHOT GUNFIRE EXPLOSION CRASH BANG THUD CLANG FOOTSTEP ENGINE TIRES HORN WIND RAIN THUNDER BIRD DOG BARK CLICK CLATTER RUSTL SQUEAK CREAK SPLASH STATIC INDISTINCT INAUDIBLE CHATTER SPEAKING CONTINUES NARRATOR ANNOUNCER VOICE OVER ON TV ON RADIO`, `\b`-prefixed); (5) `tidy`: remove empty tag pairs `<(\w+)[^>]*>\s*</\1>`, collapse runs of 2+ spaces or tabs to one, trim, drop lines empty or only dashes, dots, `…`, wave marks, bullets (`^[～〜~.…\-–—•\s]*$`); when the text shrank and one line remains its leading dash is removed. `[ts:src/modules/subtitles/subtitle-cleaner.ts:22]`–`[ts:src/modules/subtitles/subtitle-cleaner.ts:140]`

### H. Hash

37. `computeMovieHash(path)` (used by rescan to fill `media_files.osdbHash`/`osdbBytesize`, S5 caller; no subtitle route passes `filePath`): open failure or size below 131072 bytes → `null`; else the OpenSubtitles hash: sum, modulo 2^64, of the file size and of every little-endian u64 of the first and last 65536 bytes; `hash` = 16 lowercase hex digits (high word then low word), `bytesize` = size. Vector set `subtitles` (`moviehash`). Nest computes the size term as `bytesize & 0xffffffff` (a signed int32 in JS), so for a size whose bit 31 is set (size modulo 2^32 of at least 2 GiB: 2-4 GiB, 6-8 GiB files, …) the negative low word borrows one from the first carry and the high word comes out exactly 1 lower, mod 2^32, than the real hash (checked: a 3 GiB file whose words sum to `0x0000000b_12345678` hashes `0000000ad2345678` instead of `0000000bd2345678`); provider hash lookups never match for such files. [new] C?12: Rust computes the true hash (the engine's `/v1/probe` `moviehash` option already does, `[engine:docs/spec/probe.md:38]`); stored wrong values are replaced when the file is next re-enriched (rescan enrich and every import go through the post-import `finalizeImportedFile`, `[ts:src/modules/media/media-service/media-rescan.service.ts:256]`, `[ts:src/common/post-import/post-import-queue.service.ts:175]`); the vector set includes sizes `2^31`, `3·2^30`, `6·2^30` (true values, no Nest-recorded expectation) and `5·2^30` (bit 31 clear: control, equal to Nest). `[ts:src/modules/subtitles/moviehash.ts:13]`–`[ts:src/modules/subtitles/moviehash.ts:68]`
