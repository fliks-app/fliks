6. Three different normalisations exist and are not interchangeable: quality/attributes `norm` = replace every `.` with a space then lower-case `[ts:src/common/release-parsing/quality.parser.ts:12]`–`[ts:src/common/release-parsing/quality.parser.ts:14]`, `[ts:src/common/release-parsing/attributes.parser.ts:62]`–`[ts:src/common/release-parsing/attributes.parser.ts:64]`; language `norm` = replace each of `.`, `_`, `-` with a space then lower-case `[ts:src/common/release-parsing/language.parser.ts:8]`–`[ts:src/common/release-parsing/language.parser.ts:10]`; custom-format `norm` = drop every char outside `[a-z0-9]` (case-insensitively) then lower-case; the `i` flag has no `u`, so no non-ASCII char survives (U+017F, U+212A are dropped): Rust keeps `char::is_ascii_alphanumeric`, never a Unicode `(?i)` class `[ts:src/modules/profiles/custom-formats.service.ts:20]`–`[ts:src/modules/profiles/custom-formats.service.ts:22]`. Nothing else is normalised: the season/episode parser, `extractMediaTitle` and the title tokenizer read their own inputs (rules 19, 24, 31).
7. Regex semantics (S3 precedent `parse_release_quality`: `\b` -> `(?-u:\b)`): every fixed pattern is a JS pattern without the `u` flag, so `\b`, `\d`, `\w` are ASCII, `\s` is the JS whitespace set (`js::is_ws`: Unicode White_Space minus U+0085 plus U+FEFF), `.` excludes line terminators, `i` folds with `toUpperCase` (U+212A KELVIN SIGN does not match `k`; Rust's Unicode `(?i)` does). The port picks per pattern the Rust form that satisfies the vectors; fixed patterns that use lookahead/lookbehind (`SEASON_X_EPISODE_RE`, `SEASON_DASH_EPISODE_RE`, `SEASON_ONLY_RE`, `NUMBERED_SPECIAL`, `EPISODE_ZERO`, the `\.(?!\d{4})` split of `naming.md`) use `fancy_regex` (already a dependency since S3). The generated corpora MUST contain, for every regex family, the divergence characters: U+212A, U+017F (long s), `İ`, `Σ`/`ς`, Arabic-Indic and fullwidth digits, U+00A0, U+FEFF, U+0085, U+2028, accented letters adjacent to keywords (`Éfrench`, `frenchÉ`). No pattern of these files relies on `lastIndex` (the only `g` patterns go through `matchAll`/`replace`). The vectors decide; this spec does not guess a translation. `[ts:src/common/release-parsing/season-episode.parser.ts:45]`–`[ts:src/common/release-parsing/season-episode.parser.ts:66]`
8. Case and Unicode: `String.prototype.toLowerCase` equals Rust `str::to_lowercase` on the vector corpus (both apply Final_Sigma; `İ` -> `i̇`); `normalize('NFD')`, `normalize('NFKC')` need `unicode-normalization` (a new `fliks_domain` dependency, rule 54); `\p{L}`, `\p{N}` and naming's `\p{Diacritic}` are `regex` classes (`regex-syntax` 0.8 has `Diacritic`). Unicode table versions (ICU in Node 24 vs the crates) can differ on new code points: the vectors decide.

### C. Attributes

14. `parse_release_attributes(title)`: `t = norm(title)` (rule 6) feeds every detector except `releaseGroup`, which reads the RAW title. Detectors return the FIRST matching branch in listed order: resolution (4320 for `4320p?|8k`, 2160 for `2160p?|4k|uhd`, `1080[ip]?`, `720[ip]?`, then `(576|480|360)p?` giving that number, else 0); source (`remux`, `bluray` incl. `bdr`, `web-dl`, `webrip`, `hdtv`, `dvd` incl. `dvd-?r`, `sdtv`, `cam`, `ts` incl. `telesync`, `tc` incl. `telecine` with NO `\b` (`\btc\b|telecine`: `telecined` matches), else null; note `web-dl` is tested before `webrip`, and `cam`/`ts`/`tc` after the sources, the reverse of `parseReleaseQuality`); video codec (`h265`, `h264`, `av1`, `vp9`, `xvid`, `mpeg2`; `h\.?265` can never see a dot because `norm` removed it, so `h.265` is read as `h 265` and matches nothing: pinned); audio codec (`truehd`, `dts-hd`, `dts`, `eac3` incl. `ddp`, `ac3` incl. `dd5`, `flac`, `aac`, `opus`, `mp3`); edition (`directors-cut` incl. a bare `dc`, `extended`, `theatrical`, `uncut`, `remastered`, `criterion`, `imax`). `[ts:src/common/release-parsing/attributes.parser.ts:66]`–`[ts:src/common/release-parsing/attributes.parser.ts:121]`
15. `releaseGroup`: strip a trailing extension `\.[a-z0-9]{2,4}$` (case-insensitive) from the raw title, then take `-([a-z0-9_]+)$` (case-insensitive) and lower-case it; null when no match or when the group is one of `1080p 720p 2160p 480p hevc x264 x265 av1 h264 h265 dvd web bluray remux` (exact, after lower-casing). A trailing `-DL` of `WEB-DL` is a group `dl`, and a title ending `.x264` loses it as an "extension" first. `[ts:src/common/release-parsing/attributes.parser.ts:123]`–`[ts:src/common/release-parsing/attributes.parser.ts:136]`
16. `hearingImpaired` = `\b(sdh|hi|hearing[\s\-_]?impaired|cc|closed[\s\-_]?caption)\b` on `t`: any release with a standalone `hi` or `cc` token reads as HI (frozen). The field is read only by the subtitle scorer (S6); custom formats ignore it. `[ts:src/common/release-parsing/attributes.parser.ts:138]`–`[ts:src/common/release-parsing/attributes.parser.ts:157]`

### D. Language

17. `parse_release_language(title)`: `t = norm_lang(title)` (rule 6), then the first matching family in this order returns `lang(code)`: fr, de, es, it, pt, ja, ko, zh, ru, ar, nl, pl, tr, sv, da, no, fi; then `\bmulti\b` -> `UNKNOWN_LANGUAGE`; else `ENGLISH_LANGUAGE`. ### E. Season and episode

19. Patterns (verbatim from the TS, rule 7 for translation): `SE_RE`, `SEASON_RANGE_RE`, `SEASON_WORD_RANGE_RE`, `SEASON_LIST_RE`, `SEASON_DASH_EPISODE_RE`, `SEASON_ONLY_RE`, `SEASON_KEYWORD_RE`, `SEASON_X_EPISODE_RE` (lookbehind `(?<![a-zA-Z\d])`, lookahead `(?!26[45]\b)`), `COMPLETE_SERIES_RE`. All are case-insensitive and applied to the raw title (no normalisation). `[ts:src/common/release-parsing/season-episode.parser.ts:45]`–`[ts:src/common/release-parsing/season-episode.parser.ts:66]`
20. `parse_season_episode(title)` tries, first hit wins: (1) `SE_RE` -> season, episode, `isFullSeason false`, `episodeEnd` = last number of the chained `-?E\d+` tail or of the `-NN` tail, kept only when greater than `episode` (`upTo`); (2) `SEASON_X_EPISODE_RE` (same episode-end rule); (3) `SEASON_RANGE_RE` then `SEASON_WORD_RANGE_RE` -> pack with `seasonEnd` only when greater than `season` (else the range is rejected and the search goes on); then `SEASON_LIST_RE` -> pack only when the listed numbers are strictly consecutive (`S01.S03` and `S04-S02` are single seasons); (4) `SEASON_DASH_EPISODE_RE` (`S2 - 04`; `(?![.,]\d)` keeps `S01 - 5.1` out); (5) `SEASON_ONLY_RE` (`S01` not followed by `E\d`) -> pack; (6) `SEASON_KEYWORD_RE` -> pack; else all null. `isCompleteSeries` = `season === null && COMPLETE_SERIES_RE.test(title)`, computed on every result. Episode 0 is a legal episode here (unlike naming rule 14). `[ts:src/common/release-parsing/season-episode.parser.ts:76]`–`[ts:src/common/release-parsing/season-episode.parser.ts:164]`
21. `coverage_of(p)`: `seasons = season === null ? null : {from: season, to: seasonEnd ?? season}`; `episodes = episode === null ? null : {from: episode, to: episodeEnd ?? episode}`; `completeSeries = isCompleteSeries`. `release_coverage(title)` composes both. `within(range, n)` is inclusive on both ends. Used by `compute_rejections` (rules 40, 43). `[ts:src/common/release-parsing/season-episode.parser.ts:166]`–`[ts:src/common/release-parsing/season-episode.parser.ts:182]`

### F. Title extractor

22. `decode_html_entities(s)`: replace each `&(?:#(x?)([0-9a-fA-F]+)|([a-zA-Z]+));` : numeric: `parseInt(digits, hex ? 16 : 10)`; a decimal reference whose digit run contains `a-f` parses only its leading decimal digits (`&#12ab;` -> code 12; `&#ab;` -> NaN -> raw); a code that is not finite, is `<= 0`, or is above 0x10FFFF stays raw; named: the table of 102 entities (`amp lt gt apos quot nbsp` and the Latin-1/Latin Extended set, `ldquo`...`euro`), case-sensitive, unknown name stays raw; `&nbsp;` decodes to a plain U+0020 space, NOT U+00A0 (pinned). Code points 0xD800-0xDFFF: JS yields a lone surrogate; Node's UTF-8 encoder writes U+FFFD to Postgres, `JSON.stringify` emits the `\udXXX` escape. A Rust `String` cannot hold one, so Rust returns U+FFFD (decided; only a file name with a literal `&#55296;` reaches it): a Rust unit test, excluded from the vectors (serde_json cannot carry a lone surrogate). `[ts:src/common/utils/decode-html-entities.ts:12]`–`[ts:src/common/utils/decode-html-entities.ts:46]`
23. `extract_media_title(rawName)`: (a) decode entities, strip a trailing `.torrent` (case-insensitive), then strip the last `.ext` when that last `.` is not at index 0 and the lower-cased extension is in `VIDEO_EXTS` (`.mkv .mp4 .avi .mov .ts .m2ts .wmv .flv`; shared constant with the ingest spec, create it in `fliks_domain::media` if absent); (b) `se = parse_season_episode(decoded)`; (c) years = every `\b((?:19|20)\d{2})\b` of the full string; `SE_CUT_RE` is searched on the string and its FIRST match index is the cut (the TS comments say "last", the code uses `exec` once: pinned as the code); years before the cut when there is a cut, else all years; `year` = the first of them or null; (d) title slot: before the cut; else before the first `\b<year>\b`; else before the first `METADATA_CUT_RE` token; else the whole string; (e) `prettify`: `[._]+` -> space, strip a trailing `\s*\(?\b(19|20)\d{2}\)?\s*$`, `()[]{}` -> space, collapse whitespace, strip leading/trailing `[\s\-:]`, trim; `searchKey` = lower-cased title with `[^a-z0-9]+` removed; `kind` = `series` when `se.season !== null`, else `movie` when `year !== null` and there is no cut, else `unknown`. `season`, `episode`, `isFullSeason` come from `se`.
