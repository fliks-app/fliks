# Spec: ingest (library-ingest, file-transfer, post-import queue, rescan, disk import, orphans, relink)

This is the area where the server writes to real filesystems. Every filesystem operation is listed in rule group B with its path computation, its syscalls and its failure behaviour; the invariants of group A are what the server enforces at **every** write site; the escape tests are listed under Vectors/parity (cases V1-V20). Tests and parity run on generated media under `/tmp/fliks-parity/`, never on real media.

Naming (`fliks_domain::naming`) and release parsing (quality from file name and resolution, title and release-group extraction) are specified elsewhere (naming and release-parsing vectors); this spec uses their results and only constrains what is done with them.

## Routes

4 routes (`/api/imports/library/...` and `/api/imports/orphans/preview`). The plugin `library.ingest` host method is not a route (rule 100). ## Rules

### A. Path model and safety invariants (apply to every write site below)

1. Terms. `L` = `libraries.path` (the stored string after path sanitising, absolute, libraries rule 37). `M` = the media directory = the `Media.path` getter: `null` when the library has no path, `L` when `folderName` is empty or null, else `L` joined with `folderName` (lexical join: `..` collapses). A media with an empty `folderName` is a **root-level movie**: it owns only files sitting directly in `L` (rescan, companions and artwork never walk `L` for it). `media_files.relativePath` is relative to `M`, `/`-separated; readers normalise `\` to `/`.
2. Containment is enforced relative to `L`, not only to `M`: `M` is `L` joined with `folderName`, so `folderName` is validated at every writer (rule 3), because a `folderName` of `..` would make `M` the parent of `L` and every `relativePath` check pass against that `M`. Ingest also skips a destination that escapes `M` (lexical `relativePathUnderMediaRoot`). Deletes check `realpath` containment (rule 5, media-write rule 71).
3. One `fliks_domain::naming` folder-name validator, applied by every `folderName` writer (with `importers.md` rule 36 and `naming.md` rule 10), checks it as exactly one path component; a failing name is REJECTED, never mapped to `''` (an empty name makes the media path the library root): non-empty unless the media is a root-level movie, not `.` or `..`, no `/`, `\`, NUL or ASCII control character, at most 255 bytes UTF-8, no leading or trailing space or trailing dot. Writers: metadata import (media-write rules 13, 17), `createUnmatched` and `relink` in place (rules 81, 83), the first-import pin in `confirmImport` (rule 92), `PUT /api/media/:id` never writes it. A violation is a 400 (routes) or a per-file `errors[]` entry (batch paths), never a partial write. Computed names (season folder, file base name + extension) get the same single-component check (rule 4).
4. Every name the ingest computes is validated before any `mkdir` or transfer: the season folder component (empty is allowed: files land in `M`), the file name `newBaseName + ext`: base non-empty after trimming, not `.`/`..`, no separator or control character, whole name at most 255 bytes UTF-8 (the base is truncated at a character boundary, never the extension), `ext` (lowercased) must be in `VIDEO_EXTS` (`.mkv.mp4.avi.mov.ts.m2ts.wmv.flv.webm.m4v.mpg.mpeg.ogm.mts`). The video-extension check applies to every caller (disk import and plugin ingest).
5. Containment predicate `within(L, p)`. `Lc = realpath(L)` must exist and be a directory (else the operation fails before any write; a missing root is never created by ingest, rescan or delete). For a target `p` the deepest existing ancestor is resolved with `realpath` and must have `Lc` as a **strict** ancestor (equal to `Lc` only for a file created directly in `L` by a root-level movie (the EDL upload and a companion unlink), or for the one-file creates of rule 6). `..` components never appear after rule 3-4. A symlinked intermediate directory is allowed only when its realpath is still inside `Lc` (a user may symlink a title folder to another disk of the same library tree, never out of it). The check runs after `mkdir -p` (the created components are re-resolved) and again immediately before each destructive call; the final component of a create is opened with `O_CREAT|O_EXCL|O_NOFOLLOW` or linked with no-replace (rule 12).
6. Inside a library tree, directories are never created or removed outside this closed list (W11/W12 work in the cache and data dirs; the sidecar `mkdir -p` of W18 belongs to the subtitles spec): `dirname(dest)` under `M` for an ingest (rule 8); the library path itself by `libraries.md` rule 37 only; the media folder by `DELETE /media/:id` (media-write rule 70, which never removes `Lc`, an ancestor of another library root, a descendant-or-equal of another library root, or another media's directory: such a folder is kept with a `WARN` and SSE `media.files.delete_failed`, and the row still goes). Rescan creates nothing.
7. Source side. `copy` leaves the source untouched; `move` removes it. A source is accepted only as a regular file after `realpath` on every caller (a symlink is resolved and the real file operated on, so a move never relocates a link into the library, and a dangling or special file is refused). Sources are otherwise unrestricted for the disk-import routes (rule 71 gates them by `settings.access`) and limited to the plugin's consented `ingestRoots` for the plugin path (rule 100).

### B. Filesystem write inventory (every write)

Legend: *path* = how the target is computed; *calls* = syscalls in order; *fail* = behaviour on error. `W` ids are referenced by `media-write.md`.

| Id | Operation | Path | Calls | Fail |
|---|---|---|---|---|
| W1 | create the destination directory | `dirname(dest)` = `M` or `M/<seasonFolder>` (rule 8) | `mkdir -p` (mode 0777 & umask, every missing ancestor) | throws, import fails for that file (earlier files stay) |
| W2 | atomic copy | `tmp = dirname(dest)/.fliks-tmp-<uuid v4>`, then `dest` | `copyFile(src,tmp)`; open `tmp` `r+`, `fsync`, close; if `dest` exists `chmod(tmp, mode(dest) & 07777)`; no-replace rename `tmp` to `dest` (rule 12), 5 attempts 100 ms apart on `EBUSY` (Windows also `EPERM`,`EACCES`); on any error `rm -f tmp` | throws after tmp cleanup; an existing `dest` is never replaced (`AlreadyPresent`, rule 12) |
| W3 | reap stale temps | `dirname(dest)/.fliks-tmp-*` | after every successful W2, detached: `readdir`, `stat`, `unlink` when `mtime` older than 24 h; every error swallowed | never fails a transfer; unlinks only regular files whose `lstat` is not a symlink |
| W4 | move | `src` to `dest` | W1, no-replace `rename(src,dest)` (no retry); `EXDEV` then W2 then `unlink(src)` (an `unlink` failure is logged, the move counts as done); other errors throw | throws; never replaces `dest` (rule 12) |
| W5 | companion transfer | `destDir/<newBase>[.<lang hint>]<ext>` | per matching entry W1 + W2 or W4; errors logged `WARN`, skipped, never thrown | a failed companion never fails the video |
| W6 | remove the stale EDL of a replaced video | `resolveEdlPath(dest)` = `<dir>/<stem>.edl`, else a case-insensitive sibling | `lstat`, else `readdir` scan, then `rm -f` | logged `WARN` |
| W7 | delete a superseded file | `join(M, file.relativePath)` | `unlink`; W8; subtitle sidecars (rule 56) | per file: logged `WARN`, file kept, next |
| W8 | remove an orphaned EDL | `resolveEdlPath(video)` (as W6) | `readdir(dir)`; skipped when another video of the directory shares the stem (case-insensitive, `VIDEO_EXTS`); else `rm -f`; runs even when the video unlink hit `ENOENT` | logged `WARN` |
| W9 | carry subtitle sidecars over | previous and new sidecar under `M` (subtitles spec) | `rename(src,dest)` when `dest` does not exist | logged `WARN`, row kept as is |

W13-W16 (`rm -rf` of a media folder, W13, media-write rule 72; unlink of a video, W14, rule 78; EDL upload, W15, rule 91; companion unlink, W16, rule 93) are in `media-write.md`.

### C. file-transfer

8. Destination of an ingested file (computed per file, in this order): `ext` = the extension of the file name (original case kept; the lowercased form is validated, rule 4); movie: `destDir = M`, `newBaseName` = the movie naming format (`formats.movie`) applied to `{title, originalTitle, year, quality, releaseGroup, tmdbId}`; series (any non-movie type): `newBaseName` = the series naming format (`formats.series`) applied to `{seriesTitle, season: seasonNumber ?? 1, episode: episodeNumber ?? 1, episodeTitle, quality, releaseGroup, airDate}`, `destDir` = `M` joined with the season folder format (`formats.seasonFolder`) applied to `{season: seasonNumber ?? 1}`; `destPath = destDir` joined with `newBaseName + ext`. A file with no parsable numbering is placed as `S01E01`.
9. Transfer `(src, dest, method)`: W1 first (also on `copy`), then `copy` = W2; `move` = `rename`, falling back to W2 + `unlink(src)` only for `EXDEV`. After a cross-device copy whose `unlink(src)` fails the call succeeds and the orphan source stays (logged `WARN`).
10. W2 properties: the temp lives in `dirname(dest)` so the final `rename` is on one filesystem and atomic; its name is fixed length (`.fliks-tmp-` + 36 characters) so it never exceeds `NAME_MAX`; the data is `fsync`ed but the directory is not; permission bits are copied from the source by `copyFile` and from an existing destination by `chmod`; owner, mtime and xattrs are not preserved (mtime = copy time). A reader never sees a partial `dest`: either the previous file or the complete new one.
11. `.fliks-tmp-` files are invisible to the app (not video extensions) and are reaped only by W3. Windows differs only in the rename retry codes.
12. A transfer never replaces an existing file unless the caller asked to overwrite (rule 22): W2's last step is a no-replace rename (`renameat2(RENAME_NOREPLACE)` on Linux, `link` + `unlink(tmp)` where unsupported, `MoveFileEx` without `MOVEFILE_REPLACE_EXISTING` on Windows), `move` on one filesystem the same; a lost race returns `AlreadyPresent` for that file, not an overwrite, so two concurrent ingests of one destination have exactly one writer. `uniquifyOnCollision` tries `(2)` to `(99)`; the 99th collision is an error entry.
13. A source equal to the destination (same realpath, or the same device and inode) is not transferred: the file is linked in place (row created, `alreadyPresent` untouched). Re-running `reorganize` on a file already at its layout path therefore never renames it to `<name> (2)`.
14. Companions. `transferCompanions({srcDir, destDir, sourceBaseName, newBaseName, method, allowedExts})`: list `srcDir`, unreadable directory = return. For each entry: only regular files (a symlink or directory entry is skipped); `ext` = lowercased extension must be in `allowedExts`; `stem` = name minus extension; the stem must **start with** `sourceBaseName` (both lowercased); `.edl` only with an exact stem match. Destination name: exact stem match → `<newBaseName><ext>`; otherwise the trailing language hint `stem.match(/\.([a-z]{2,3}(?:\.[a-z]+){0,2})$/i)` keeps the whole hint (`name.en.hi.forced.srt` keeps `en.hi.forced`) → `<newBaseName>.<hint><ext>`; no hint → `<newBaseName><ext>`. Each is W5.
15. Companion guards: the stem prefix test has no boundary (so `Movie 2.srt` matches the video `Movie.mkv`); a companion whose stem starts with the stem of a **longer-named video in the same directory** is claimed by that video and skipped (the `claimed` rule of the companion listing); a companion never replaces an existing file, so of two non-exact companions with the same extension mapping to one destination name the first is kept; both cases log `WARN` and leave the source in place on `move`.
16. `getCompanionExts`: `SELECT value FROM app_settings WHERE key = 'companion_file_extensions' LIMIT 1`; `value ?? DEFAULT` (default `.srt,.ass,.ssa,.vtt,.idx,.sub,.nfo,.jpg,.jpeg,.png,.webp,.edl`); split on `,`, trim, lowercase, drop empties, prefix `.` when missing. A stored empty string yields an empty set (no companions at all).

### D. library-ingest

17. `ingest(req)`: `req` = `{mediaId, files: [{path, episodeId?, size?}], transfer: 'copy'|'move', fallbackQuality?, releaseName?, sourceLabel, force?, uniquifyOnCollision?, replaceExisting?}`; result `{imported: [{file: MediaFile, episodeId?, seasonId?, sourcePath}], alreadyPresent: string[]}`. Callers: disk import (`confirmImport`, rule 92; `uniquifyOnCollision` only for reorganize, never `replaceExisting`) and the plugin `library.ingest` (`replaceExisting: true`, `releaseName = sourceLabel`, rule 100).
18. Preconditions, all plain errors (the plugin caller sees the message; disk import turns it into an `errors[]` entry, rule 92): media missing `Media #<id> not found`; `media.path` null `Media #<id> is not anchored to a library folder`; empty `folderName` `Media #<id> has no folder of its own, refusing to place files at the library root`; `files: []` returns `{imported: [], alreadyPresent: []}`. Plus rules 3-5 (folderName and path containment).
19. File selection: a **season pack** is `type = series` with more than one file: every file is its own episode. Any other request keeps only the largest file (each source is `stat`ed; on equal sizes the later file wins) and ignores the rest (samples, proofs and extras ride in the same download folder). A one-file request is unaffected.
20. Episode resolution per file (non-movie only): `epNums` = the episode numbers parsed from the file name (without extension, with the path), else from `releaseName`, giving `{season, episode, episodeEnd?}`. A caller `episodeId` is authoritative only when `SELECT e.*, s.* FROM items e JOIN item_groups s ON s.id = e."groupId" WHERE e.id = $1 AND s."mediaId" = $2` finds it (else `WARN` and filename parsing); then `episodeNumber/seasonNumber (default 1)/title/airDate` come from the row. Else with `epNums`: `seasons WHERE "mediaId" = $1 AND "number" = $2`, then `episodes WHERE "groupId" = $1 AND "number" = $2`; a found episode whose `endEpisodeNumber` differs from `epNums.episodeEnd` is updated only when `epNums.episodeEnd` is set (`UPDATE items SET "endNumber" = $2`; a name without a range never clears one); a missing season or episode leaves the ids unset (**ingest never creates seasons or episodes**; the file is stored with no part). Else no numbering: season 0 with its episodes, `matchSpecialByTitle(sourceBase, episodes)`; a match sets season 0 / the episode, no match no link.
21. Quality: the engine probe of the **source** (a bad file yields `{video: [], audio: [], subtitles: [], error}`, stored as `streamInfo`; an unreachable engine **errors**, which aborts the call at that file before its transfer, earlier files stay); with dimensions, `quality` = the quality from resolution of `releaseName ?? basename(file.path)`, width and height (pixels win over the release label: a mislabeled 2160p of 1920x804 is 1080p); else `req.fallbackQuality ?? ''`. `releaseGroup` = the release group extracted from `releaseName`, when given.
21a. Truncation check, on the **source**, after the probe, the layout and the collision test (a file already present or at its place is not scanned) and before any write: when the probe has a video stream and a `durationSeconds`, the engine `Scan` job runs at `high` priority and is waited for up to 5 min (then cancelled). `readable = scan.end - (formatStartSeconds ?? 0)`. The file is **truncated** when `durationSeconds - readable > max(120 s, 5 % of durationSeconds)`: its data ends far before the duration the container declares, as an interrupted or preallocated download imported as complete. A truncated file is refused as an error entry `<name>: truncated file, its data ends at <mm:ss> of the <mm:ss> its container declares`: no transfer, no companions, no row, the source stays where it is, the next files of the call still run. The check never refuses on doubt: no video, no declared duration, a scan that fails or is not done in time, or a scan with `breakSeconds` (a clock break is another defect, `playback-info.md` rule 48) lets the import proceed. The scan is kept for the imported file when the source is unchanged since the scan and the placed file has the source's size (a move, a hard link or a finished copy: the scan describes bytes), stored against the placed file's own size and mtime before the call returns, so nothing queues a scan of the placed file first; else the post-import scan (rule 35) runs as before. The plugin caller learns of the refusal through the existing failure channel (rule 100): the call fails `ERR` when nothing was imported; the disk import lists it in `errors[]` (rule 92). Only `ingest` applies it: rescans, in-place links and files already in the library are untouched.
22. Collision. `relativePath = relativePathUnderMediaRoot(M, destPath)`; null = `ERROR computed dest outside media folder` and the file is reported as an error entry. `collides(rel, abs)` = the file exists at `abs` or a `media_files` row (mediaId, relativePath) exists. `sourceSize` = size of the source (0 on failure). `overwrite = force || (replaceExisting && !sameSize(dest, sourceSize))` (`sameSize` = a destination of equal size exists: a retried import is a no-op). Without `overwrite` and colliding: no `uniquifyOnCollision` → push the source path to `alreadyPresent`, continue (companions are not touched); with it → `n = 2..99`, `base = "<newBaseName> (n)"`, destination `destDir/base+ext`, until free; `(99)` taken is an error entry.
23. Write order per file, failures abort the **whole call** at that file (earlier files stay written and persisted): log; `transferFile` (W1, W2 or W4); when `overwrite || replaceExisting` the stale EDL of `dest` is removed (W6); `transferCompanions` with `srcDir = dirname(file.path)`, `destDir`, `sourceBaseName = basename(file.path)` minus ext, `newBaseName`, `allowedExts` (W5); then `finalSize = stat(dest).size` (fallback `file.size ?? sourceSize`); then the row.
24. Row: `payload = {episode: {id} | null, size: finalSize, quality, streamInfo?}`; `SELECT * FROM media_files WHERE "mediaId" = $1 AND "relativePath" = $2`; found → `UPDATE media_files SET size, quality, streamInfo, "updatedAt"` (an overwrite re-imports onto its own row); else `INSERT INTO media_files ("mediaId","relativePath",size,quality,"streamInfo")`. Then the file's parts are replaced (`items.md` rules 19, 23): the episode of rule 20 and, when the name spans a range, the existing items of the same group up to `episodeEnd`; a movie's file is a part of its item; a series file with no episode gets none. There is no transaction: a failure after the transfer leaves the file in the library with no row (a later rescan adopts it).
25. After the loop (only when something was imported): `replaceExisting` → superseded removal (rules 29-33); domain event `media.files.imported {mediaId, family: 'video', seasonNumber?, episodeNumber?, source}` where season/episode numbers are present only when exactly one file was imported and it has them, `source = releaseName ? 'download': 'disk'`; then `postImportQueue.enqueue({mediaFileId})` per imported file (rule 36). Returned `imported[]` drop the internal fields.
26. `replaceExisting` semantics: see rules 29-33. `force` is an internal flag no caller sets.
27. Ordering and concurrency: one in-process async mutex per media id surrounds `ingest`, `rescanFiles`, `linkExistingFileInPlace`, media delete and file delete (single server process); it is held for the whole operation including the transfer. The in-memory `Rescan:<id>` activity claim additionally serialises two rescans.
28. The plugin `idempotencyKey` is not consumed (the guarantee is the collision rule: a retry resolves the same destination with the same bytes and lands in `alreadyPresent`); the plugin host keeps that guarantee and does not add a key store.

### E. Superseded removal (`replaceExisting`)

29. Runs after all new files were written. `others = media_files WHERE "mediaId" = $1 AND id NOT IN (<new ids>)` with `episode` and `episode.season`. `covered` = the set of `season:episode` keys the imported files span (`episodeNumber..episodeEnd`, single number when no end).
30. Per superseded file, in order, inside a `try` whose failure logs `WARN could not remove superseded "<rel>"` and moves on to the next superseded file (that file then stays on disk and in the DB, but its carried subtitles have already moved to the heir: no rollback): movies: `heir = imported[0].file`; series: a superseded file with no episode or no season is kept; it is kept unless every number of its span is in `covered`; `heir` = the imported file covering exactly that single episode with no range (none when the superseded file spanned a range). Then: subtitle carry-over to `heir` when it exists (subtitles spec, W9; returns the moved subtitle ids); watch progress needs no carry, since it belongs to the item and a deleted file only clears the last file played (`playback_states."mediaFileId"` is `ON DELETE SET NULL`); then `deleteMediaFile(mediaId, superseded.id, deleteOnDisk = true)` (media-write rule 78: W7).
31. After each successfully removed superseded file: if its episode had `endEpisodeNumber` and no imported file of that episode carries an `episodeEnd`, `UPDATE items SET "endNumber" = NULL WHERE id = $1`.
32. Detached after the call returns: for each carried subtitle id, sequentially, a subtitle sync with `automatic: true` (subtitles spec; failures logged `WARN`, the subtitle kept).
33. The deletion of a superseded file goes through the same contained unlink as every other file delete (media-write rule 78): a `relativePath` that is absolute, contains `..` or NUL, or whose resolved parent is not inside `Lc`, is never unlinked (the row is still removed, `WARN`; the file-delete route answers 400 `Invalid file path` and keeps the row). A symlink is unlinked, never followed, and a superseded file that is not a regular file on disk is only unlinked, never `rm -rf`ed.

### F. Post-import queue

34. In-memory FIFO of `{mediaFileId}`, concurrency 1 (`ENRICH_CONCURRENCY`), de-duplicated by `mediaFileId` while queued or running (`enqueue` of a queued id is a no-op). It is **not persisted**: a restart drops the backlog and nothing re-enqueues it (a `RescanMissingFiles` does not either, rule 59).
35. Per task: load the file with `media`, `episode`, `episode.season`; missing file, no `media.path` or empty `relativePath` → `WARN`, task dropped. `absPath = join(resolve(media.path), relativePath with \ → /)`, contained like rule 5 (a path outside `Lc` is dropped). Then `finalizeImportedFile(file, absPath)` (rule 50) and the file's source scan (`playback-info.md` rule 49, priority `normal`, detached so the queue does not wait on it: the new bytes are still in the page cache, and a play right after the import finds the scan), then the subtitle scheduler's media-file-imported hook (`mediaId, fileId, episodeId?`). Each step's error is logged `WARN` and never stops the queue.
36. Progress: a wave = everything queued until the queue drains. `waveTotal++` at enqueue, `waveDone++` at task end; both reset when idle. SSE `task.progress` broadcast `{command: 'PostImportEnrich', current: waveDone, total: waveTotal, message: <formatted subject or ''>, subject?}` on enqueue, on task start (subject of the file) and on every task end; the final one (after the last task, subject cleared) has `current = total`. Activity registry: `upsertPending('PostImportEnrich:<fileId>', 'PostImportEnrich', undefined, parent 'PostImportEnrichQueue')` at enqueue, `upsertRunning` at start, `remove` at end; the parent row `PostImportEnrichQueue` is `upsertRunning(..., subject, waveDone, waveTotal)` while `pendingCount > 0`, removed when idle. `whenIdle` resolves when `active == 0 && tasks == 0`.
37. Settle timer (the post-import service, the consumer of the queue; listed here because it reads `whenIdle`): on domain `media.files.imported` → `schedule(mediaId)` (re-armed per event, 60 s `SETTLE_MS`); on SSE `rescan.completed` → `schedule` when `added > 0`, and `scanSources(mediaId)` (per file of the media, sequential: the source scan of every file lacking one of its current bytes) in every case. When it fires: wait for `whenIdle` or 5 min (`QUEUE_IDLE_CEILING_MS`), sprites for missing files when `sprites_auto_generate_on_import` is unset or exactly `'true'`, then marker auto-detection for the media unconditionally, which itself returns unless `markers_auto_detect_on_import` is unset or exactly `'true'`; any other value (`'1'`, `'False'`) disables. All failures logged. The timers are in memory.

### G. Rescan

38. `rescanFiles(mediaId)` is the one function the routes (media-write rule 59), the scheduler jobs (`RescanAll`, `RescanMissingFiles`) and `identify` (media-write rule 50) call; result `{added, removed, updated, subtitleRemovedMissing, subtitleRemovedDuplicates}`. Load: media with `files`, `files.episode`, `files.episode.season`; missing → 404 `Media #<id> not found`; `media.path` null → 400 `Media #<id> has no root path configured`. `mediaDir = resolve(media.path)`.
39. Rescan refuses a missing media folder: `mediaDir` (and `Lc`) must exist and be readable directories, else 400 `Media folder not found: <dir>` and **no row is touched**. This protects an unmounted library: a rescan that created the missing folder and found nothing would delete every `media_files` row of the media (rule 42), cascading to `subtitle_files`, `media_file_scans` and `item_parts` (an item with no other file has no file) and setting every `playback_states."mediaFileId"` that named a deleted file to NULL (watch progress stays on its item); a root-level movie (`mediaDir = L`) is protected the same way, and `RescanAll` (rule 55) skips every media of the library. A media with no file rows and a missing folder (a fresh import, rule 13 of media-write) returns all-zero counts instead of the 400: there is nothing to remove.
40. Disk walk (only when `folderName` is non-empty): `collectVideoFilesRecursive(mediaDir, depth 0)`: depth greater than 3 is skipped with `WARN`; a directory listing failure = `ERROR` and **zero files for that directory** (the removal pass is then skipped, rule 41); a directory entry (links not followed) recurses; any other entry with a `VIDEO_EXTS` extension is a candidate (regular files only, rule 41); a file already linked (its `relativePath` in the known set) is always kept; a new file is skipped when any ancestor below the media root is a bonus directory (`/^(samples?|extras?|featurettes?|trailers?|interviews|behind[._-]the[._-]scenes|deleted[._-]scenes)$/i`) or the name ends in a `sample` token (`/(?:^|[.\-_ ])sample$/i` on the stem). Each path is rechecked with `relativePathUnderMediaRoot(mediaDir, f)`.
41. A removal pass runs only when every directory visited was listed successfully (one failed directory listing aborts the removals, `WARN`, adds and updates still run); candidates must be regular files (`stat` of the target, links followed, FIFO/device/socket skipped, so a FIFO named `x.mkv` is never probed). With an empty `folderName` nothing is walked: only the media's own known files are `stat`ed (the root is shared with sibling root-level movies).
42. Step 3, removal: for each DB row whose normalised `relativePath` is empty or not in `diskRelPaths`: `ERROR` when it contains `..`; `DELETE FROM media_files WHERE id = $1` (cascades `subtitle_files` of the file, and clears `playback_states."mediaFileId"`; `media_file_scans` and its `item_parts`, so an item with no other file has no file); thumbnails/sprites dropped (`deleteForFile`, W11, detached); `removed++`. The rows are deleted in one statement; a failure is logged and the pass continues.
43. Step 4, refresh of rows still on disk: `stat` failure skips the row; series: `epNums = parseEpisodeNumbers(filename, absPath)`; row without episode (no part) and `epNums` → `ensureSeasonAndEpisode` (rule 45), parts written for the episode and its range, `updated++`, `metadataSlotsCreated` when a season/episode was invented; no episode and no numbers → `matchSpecialFile` (season 0 title match) and link; linked row with `epNums.episodeEnd` differing from its episode's `endEpisodeNumber` → `UPDATE items SET "endNumber"` and the items inside the new range gain the parts of its owner (`items.md` rule 19). Then skip the probe and the `UPDATE` (no `updated++`) when `row.size == diskSize`, `row.mtimeMs` equals the file's mtime in ms and `row.probeVersion` is the current `PROBE_VERSION` (both columns are `NULL` until a rescan stamps them, so existing rows are probed once more); otherwise re-probe: `sizeUnchanged = row.size == diskSize`; `size = diskSize`; `probeAndResolve(absPath, filename, {detectCrop: !sizeUnchanged})`; on an unchanged size the previous `video[0].crop` is carried over; `timestampBreakSeconds` of the previous `streamInfo` is always carried over; `quality` replaced only when the probe gave dimensions (never downgraded to the filename guess); `UPDATE media_files SET size, quality, streamInfo, mtimeMs, probeVersion`; `updated++`; a changed size also calls the engine `invalidate(fileId)` (detached); a changed size, or a stored mtime that differs from the file's, schedules the file's source scan (an unstamped row alone does not) (`playback-info.md` rule 49, priority `normal`, detached). Seasons, episodes and season-0 specials are loaded once per rescan; the missing slots, the links, the new rows (`ON CONFLICT DO NOTHING`), the removals and the parts are each applied in one batch per rescan.
44. Step 5, new files (`diskFiles` not in the known set): `stat` failure skips; series: with `epNums` → `ensureSeasonAndEpisode`, else special match, else `WARN... skipped, alien file in series folder` and the file is **not added**; movies need nothing. `probeAndResolve(..., {detectCrop: true})`; `quality = probe quality ?? qualityFromResolution(filename)`; `INSERT INTO media_files (mediaId, relativePath, size, quality, streamInfo, mtimeMs, probeVersion)`; `added++`; parts for its episode and range, or for the movie's item. The new rows go in one batch; when it fails, each row is retried alone, so only a row that still fails is logged (with its path) and skipped.
45. `ensureSeasonAndEpisode(media, {season, episode, episodeEnd?})`: `item_groups WHERE ("mediaId", number)` else `INSERT item_groups ("mediaId", number, monitored = number > 0)`; `items WHERE ("groupId", number)` else `INSERT items ("groupId", "mediaId", "editionId" = the media's `video` edition, number, "endNumber" = episodeEnd ?? null, monitored = true)` (`items.md` rule 8); an existing episode whose `"endNumber"` differs from `episodeEnd` (when set) is updated; the items inside a range then gain the parts of its owner (`items.md` rule 19). Returns `{ep, created}`; `created` is true when either row was new.
46. `probeAndResolve(absPath, filename, {detectCrop})`: `detectMediaFileInfo` (rule 21; a throw is `ERROR` and returns `null`, and every caller then skips that row or file without counting it); with a video stream and `detectCrop`, `detectCrop(absPath)` sets `video[0].crop` when non-null (failure `WARN`, kept); `quality = qualityFromResolution(filename, w, h)` when `video[0]` has both dimensions, else `null` (callers decide).
47. Subtitle housekeeping after the walk (subtitles spec callees, one `try`, any failure `WARN`): reconcile subtitle files after rescan (row-only: removes external rows whose file is gone and duplicate rows; **never** deletes files) → `subtitleRemovedMissing`, `subtitleRemovedDuplicates`; discover external subtitles (inserts rows for subtitle files found by name); then, for each file this rescan added, re-probed or relinked to another episode, the embedded subtitle detection (`mediaId, fileId, episodeId?`, rebuilds the embedded rows from the probe); a skipped file keeps its rows. The two sidecar steps need a complete walk (rule 41); the embedded detection runs whatever the walk's completeness and even when a step above failed, since the probe stamp of those files is already stored.
48. Tail: log; when `added|removed|updated` non-zero, `mediaServers.dispatch('library.rescan', {title, path})` (detached); when a season/episode was invented, `metadata.refreshSeriesEpisodes(media)` (provider fetch; failure `WARN`), so the bare rows gain titles and stills. Returns the counts.
49. `enrichMediaFileFromDisk(fileId)`: file with `media`; no file or no `media.path` → `WARN`, return; empty `relativePath` → return silently; `absPath = join(resolve(media.path), relativePath)`; missing on disk → `WARN`, return; `stat`; `probeAndResolve(..., {detectCrop: false})`; set `size`, carry `timestampBreakSeconds`, `streamInfo`, `quality` (only when non-null); `UPDATE media_files`; `postImportQueue.enqueue`; `mediaServers.dispatch('library.rescan', {title, path})`.
50. `finalizeImportedFile(file, absPath)` (called by the queue): when `streamInfo.video[0]` exists, the crop is detected and stored as `video[0].crop` (`crop ?? undefined`); `osdbHash` and `osdbBytesize` (nulls when the file is under 128 KiB or unreadable) come from the engine probe that already yields the crop in this step (`POST /v1/probe` with `moviehash: true`), which computes the true u64 sum (files whose size has bit 31 set hash correctly); stored `osdbHash` values are recomputed on the next re-enrich (rescan or import), `subtitle-files.md` rule 37. One `save`; best-effort, errors logged.
51. `analyzeMedia(mediaId, {sprites?, crop?, subtitleCache?})`: all three falsy = return; media with `files`, `files.episode`, `files.episode.season`; 404 / 400 as rule 38; per file with a `relativePath`, `absPath = join(resolve(media.path), relativePath with \ → /)` (contained, rule 5); a file absent on disk is skipped with `WARN`; `crop` → `detectAndStoreCrop` + `save` per file (awaited); `subtitleCache` → detached engine job `{kind: {type: 'SubtitleExtract', info: streamInfo}, media: {mediaFileId, path: absPath}, priority: 'high', force: true}` when the file has a non-image subtitle stream; `sprites` → detached sprite job `force: true, priority: 'high'` (`GenerateSprite:<id>` activity).
52. `linkExistingFileInPlace({media, absPath, epNums?})` (orphan relink, no file moved): `relativePath = relativePathUnderMediaRoot(media.path, absPath)`; null → `{error: 'file outside the media folder'}`; empty `folderName` and a `/` in the path → `{error: 'a title with no folder can only own files at the library root'}`; an existing row (mediaId, relativePath) is returned as is (`created: false`); series: `epNums ?? parse(filename)`, none → special match or `{error: 'no SxxEyy pattern found'}`; numbers → `ensureSeasonAndEpisode`. `stat` (size 0 on failure), `INSERT media_files (…, quality = parseReleaseQuality(filename).quality.name)`, its parts, then `enrichMediaFileFromDisk(newId)` (awaited: probe, crop deferred). Returns `{fileId, episodeId, created}`.
53. `linkExistingFileInPlace` additionally requires `within(Lc, realpath(absPath))`, a regular file and a `VIDEO_EXTS` extension: containment relative to `media.path` alone is not enough, because `media.path` follows the caller-chosen `folderName` (rule 2); otherwise a link-in-place of `/etc/passwd` with `folderName = "../../etc"` would create a `media_files` row the media routes then serve and (with `deleteOnDisk`) unlink.
54. `ensureSeriesEpisode(media, epNums)` returns `{episodeId, created}` from rule 45 (used by relink before `confirmImport`).
55. `RescanAll` and `RescanMissingFiles` (trigger-only jobs, scheduler spec) call `rescanFiles` sequentially per media with `yieldLoop` between; a media that throws (no path, missing folder) is counted `skipped` and logged `WARN`; `RescanMissingFiles` candidates = media with a `path` that either has no files (and a non-empty `folderName`) or, for series, has a file without episode. An unmounted library therefore makes every media `skipped` instead of emptying it (rule 39).
56. Callees owned by the subtitles specs and reached from this spec: `subtitles.carryOver`, `subtitles.deleteSubtitleFilesOnDisk`, `subtitles.deleteSubtitle`, `subtitles.reconcileSubtitleFilesAfterRescan`, `subtitles.discoverExternalSubtitles`, `embeddedSubtitle.detectAndStore`, `subtitleSync.syncSubtitle`, `subtitleScheduler.onMediaFileImported`, `subtitles.parseSubtitleFilename`, `matchSubtitleVideo`. Their disk effects are W7 (unlink), W9 (rename).
57. `thumbnails.deleteForFile(fileId)` = engine `POST /v1/invalidate {mediaFileId}` (best effort) + `rm -rf <cache dir>/thumbnails/<fileId>` (W11; numeric id, never user input).
58. `mediaServers.dispatch(event, {title, path})` is fire-and-forget outbound notification (`media-servers`); events used here: `library.rescan`, `media.deleted`, `file.deleted`.
59. Nothing in the rescan or ingest path re-enqueues work lost on restart (rule 34); the interrupted state is "file present, `osdbHash` null, no crop", healed by a manual `analyze` or rescan; no startup sweep exists.

### H. Disk import: orphan scan, preview, relink

60. Orphan scan of a library: `requirePathFor(libraryId)`; `linkedSet` = for every `media_files` row of the library, `resolve(join(media.path ?? library.path, relativePath with \ → /))` (only `id, relativePath, media.id, media.folderName, media.library.id, media.library.path` selected); then `scanOrphansUnder(library.path, library.mediaTypes ?? [], library.preferredProvider ?? 'tmdb', linkedSet)`.
61. Preview: `root = resolve(sanitizeFsPath(dto.path))` (relative paths resolve against the process cwd); `stat` failure → 400 `Path not found: <root>`; not a directory → 400 `Not a directory: <root>`; scan with `dto.mediaTypes ?? ['movie','series']`, `dto.preferredProvider ?? 'tmdb'`, an empty `linkedSet` (everything under the folder is an orphan).
62. `scanOrphansUnder`: `collectVideoFiles(root, 0)`: depth greater than 3 returns nothing; `readdir` errors return nothing; directories (`isDirectory`, links not followed) are descended 8 at a time; a bonus-named directory is skipped unless it sits directly in the scan root (`depth > 0 && isBonusDir(name)` evaluated in its parent); other entries with a `VIDEO_EXTS` extension that are not sample files are collected. `unlinked = files not in linkedSet` (compared as resolved paths).
63. Pass 1 (8 in parallel, one `stat` per file): `epNums = parseEpisodeNumbers(filename, abs)`; `inferredType = (epNums || isSpecialFile(abs)) ? 'series': 'movie'`; a file whose inferred type is not in `mediaTypes` is dropped; `quality = parseReleaseQuality(filename)`; `size` (0 on `stat` failure); `rel = relativePathUnderMediaRoot(root, abs)`; `folderName = segments.length > 1 ? segments[0]: ''` (the first segment under the root; empty for a file directly in the root).
64. Pass 2 (walk order): a series file with `folderName = ''` is dropped (a series needs a folder); `orphanCount++` for the rest; group key `series:<folderName>` or `movie:<abs>` (every movie is its own group, even in one folder); a group's first file is its sample; `OrphanGroup = {groupKey, mediaType, folderName, guessTitle: folderName, guessYear: null, nfo: null, suggestedProvider, files: OrphanFileEntry[]}` with `OrphanFileEntry = {filePath: abs, filename, size, qualityName, qualityId, seasonNumber|null, episodeNumber|null, episodeEnd|null}`. Pass 3 (8 in parallel, one per group): `nfo = readForVideoFile(sampleAbs)` (reads `<stem>.nfo`, `movie.nfo`, `tvshow.nfo` beside it, then `../tvshow.nfo`; each read is capped at 1 MiB, larger = no nfo; parse errors give an empty object, never throws); `guessTitle = nfo?.title ?? extractMediaTitle(basename(sample)).title ?? folderName`; `guessYear = nfo?.year ?? extracted.year ?? null`.
65. Progress: SSE `task.progress` `{command: 'OrphanScan', current, total, message: root}` broadcast at 0, every 25th file and at the end; `total = unlinked.length + 1`; activity row `OrphanScan:<root>` `upsertRunning(..., {title: root}, current, total)`, removed in a `finally`.
66. Result: `{libraryPath: root (the library path or the resolved preview path), groups: [...groups.values] in insertion order, scannedFiles: allFiles.length, orphanCount}`.
67. The scan reads only: no DB write, no filesystem write. It lists files below any directory the process can read (preview) or below a library root (scan).
68. `findLocalArtwork(dir, basename?, {basenameOnly})` (read-only, one `readdir`, case-insensitive): candidates in precedence order `poster`: `<basename>-poster`, `poster`, `folder`, `cover`, `movie`; `fanart`: `<basename>-fanart`, `fanart`, `backdrop`; `logo`: `clearlogo`, `logo` (none under `basenameOnly`, which also keeps only the `<basename>-poster` / `<basename>-fanart` forms: the shared library root of a root-level movie); extensions `jpg jpeg png webp`. The files found are stored through the image store (`storeFromDisk`, images spec, reads the source, writes the data dir).
69. `seriesFolderOf(file, folderName, scanRoot?)`: climbs from `dirname(file)` up to (and including) `resolve(sanitizeFsPath(scanRoot))` when given, returning the **outermost** ancestor whose basename equals `folderName`, else `dirname(file)`; stops at the filesystem root; a `scanRoot` that is no ancestor caps nothing. Used only to find the artwork/nfo directory of an external series.
70. `scan` applies the library ACL (libraries rule 30; outside the caller's libraries 404 `Library #<id> not found`) and the `libraryPath` visibility rule of the library routes (the response carries it only for a caller who can manage libraries, else it is omitted).
71. `preview` and the relink routes read and move files from any directory readable by the server, so `preview` requires `settings.access` (library manager; the creation wizard is the only client) and a relative `path` is refused (400); relink with `transfer` requires the same; the parity seed's `user` actor receives 403 and `admin` succeeds.
72. Relink body: `libraryId` int >= 1 (numeric strings pass: `"2"` is accepted); `type` `'movie'|'series'`; `externalId?` string; `provider?` string; `title?` string max 255; `year?` int 1888..2100; `qualityProfileId?`, `languageProfileId?` int >= 1; `folderName` string (required, empty allowed, then rule 3); `scanRoot?` string; `reorganize?` boolean; `transfer?` `'copy'|'move'`; `files` non-empty array of `{filePath: string (required), seasonNumber?, episodeNumber?, episodeEnd?}` (ints >= 0, numeric strings accepted). Unknown keys 400. `filePath` must be absolute after path sanitising, else 400 `files.<i>.filePath must be an absolute path`.
73. `relinkOrphansBatch(items, userId)`: a per-call `batchId = 'OrphanImport:<uuid>'`; every item gets an activity row `<batchId>:<type>:<folderName>` as pending under the batch row up front; then sequentially per item: SSE `task.progress` `{command: 'OrphanImport', current: index++, total, message: folderName}`, activity rows running, `relinkOrphans(item, userId)`; counts `created`, `linked`, and `failed` when an item throws or links 0 files with 0 `alreadyPresent`; item failures are logged `WARN` and never stop the batch; all rows removed in `finally`; a final `task.progress` with `current = total`, `message = ''`; summary logged. The route returns `{queued}` before any of this.
74. The batch runs for hours on large libraries and in memory only: a restart abandons the remaining items silently (the wizard can re-run: a re-run is idempotent, rules 88 and 92).
75. The batch route has no per-item validation beyond the body schema; each item is subject to rules 76-92 individually. `relinkOrphans` first checks `dto.libraryId` against the caller's accessible libraries (outside: 404 `Library #<id> not found`), on the unmatched path too.
76. `relinkOrphans(dto, addedByUserId)` start: `libraries.requirePathFor(dto.libraryId)` (404 / 400); `dto.type` not in `library.mediaTypes` → 400; `reorganizeInPlace = reorganize && !transfer`; no `externalId` with `reorganizeInPlace` → 400 `Reorganize needs an identified title`; empty `folderName` with `reorganizeInPlace` → 400 `Reorganize needs a title with its own folder`.
77. Media resolution: `externalId` present → `findOrImportIdentified`; else `findOrCreateUnmatched` (rule 79).
78. `findOrImportIdentified`: `externalIdNum = Number(externalId)` (non-numeric → 400); lookup of the media of `type` holding the `tvdb` or `tmdb` id `n` (`external-ids.md` rule 6; `provider === 'tvdb'` selects `tvdb`, anything else `tmdb`) with `library` and `files`; missing → `mediaService.importMedia({type, externalId, provider, libraryId, qualityProfileId, languageProfileId}, userId)` (media-write rule 17: full provider import, requests hook, `media.imported`), re-read, `created = true`; any import error re-runs the lookup and reuses the row a concurrent request created, else rethrows.
79. `findOrCreateUnmatched(dto, library, userId)`: natural key `(library, type, folderName)` under an in-process keyed lock (`<libraryId>:<type>:<folderName>`; in-process only, a second fliks-server instance would bypass it). Sample = `resolve(files[0].filePath)`. Artwork/nfo directory: movies `dirname(sample)`; series with `transfer` `seriesFolderOf(sample, folderName, scanRoot)`; series in place `join(library.path, folderName)`. `title = dto.title.trim || extractMediaTitle(basename(sample)).title || folderName`; with `transfer`, `.nfo` is read first and its title replaces the guess only when the guess equals the folder fallback; `year = dto.year ?? nfo.year`. With `transfer` the folder is named by the naming layout (`applyMovieFolderFormat` / `applySeriesFolderFormat` with title and year); in place it stays `dto.folderName`. Reuse: `folderName = ''` (root movie): candidates `media WHERE library, type, folderName = ''` that already own a file whose `relativePath` equals the basename of one of the requested files; else `findOne(library, type, folderName)`.
80. Unmatched, in place only: "File outside the library root" (400) when `relativePathUnderMediaRoot(library.path, sample)` is null or the artwork directory resolves outside `resolve(library.path)` (lexical `startsWith(root + sep)`). This lexical check applies only here (skipped when an existing media is reused, absent from the identified path, rule 82); rule 89 adds the realpath containment on the other paths.
81. Create: `createUnmatched({title, year, type, libraryId, folderName, qualityProfileId, languageProfileId, libraryDefaultQualityProfileId, libraryDefaultLanguageProfileId, nfo (title cleared under transfer), artwork}, userId)` (media-write rule 19): row with `monitored = false`, status `released`, no provider ids, artwork stored from disk; then re-read with `library`, `files`; `created = true`. The lock's holder count (`unmatchedHolders`) is raised inside the lock.
82. After resolution: `media.library` set and `media.library.id != dto.libraryId` → 400 `Media already belongs to another library ("<name>")`. For an identified media that already existed in another library this fires after the lookup, nothing written.
83. Link in place (no `reorganize`, no `transfer`): when the media has no files **and** `media.folderName != dto.folderName`: `UPDATE media SET "libraryId" = $lib, "folderName" = $dto.folderName` (validated, rule 3); `media.library ??= library`. Then per file `absPath = resolve(filePath)`, `callerEpNums(f)` (both season and episode present), `linkExistingFileInPlace` (rules 52-53): an `{error}` becomes `errors[] = "<basename>: <error>"`; success `linked++`, `slotCreated ||= created`, `postImportQueue.enqueue({mediaFileId})`. `linked > 0` → domain `media.files.imported {mediaId, family: 'video', source: 'disk'}` (no season/episode). **No file is moved or written on this path**; the only risk is registering an unsafe path, closed by rule 53.
84. `reorganize` or `transfer`: for each file, `filename = basename(filePath)`; series: `epNums = callerEpNums(f) ?? parseEpisodeNumbers(filename, filePath)`; none → `matchSpecialFile` (season 0 title match) → episode, else `errors[] = "<filename>: no SxxEyy pattern found"` and the file is skipped; numbers → `ensureSeriesEpisode` (rule 54), `slotCreated ||= created`; `ImportFileEntry = {filePath, mediaId, episodeId?, quality: parseReleaseQuality(filename).quality.name, targetLibraryId: dto.libraryId}`.
85. Then `confirmImport(entries, method = dto.transfer ?? 'move', {uniquifyOnCollision: !dto.transfer})`: with `transfer` (files outside the library) a collision is `alreadyPresent`; with in-library `reorganize` (always a `move`) a collision appends ` (n)` (rule 13 fixes the self-collision). Result `linked = imported`, `alreadyPresent`, `errors`.
86. After either branch: series, `slotCreated` and the media has an external id (`external-ids.md` rule 7) → `metadata.refreshSeriesEpisodes(media)` (failure `WARN`). An unmatched media has none (no call).
87. Cleanup: an unmatched media **created by this call** with `linked = 0` and `alreadyPresent = 0` is deleted (`DELETE FROM media WHERE id = $1`) under the creation lock, only when the holder count is 1 and it still has no files (a concurrent relink that reused the row keeps it). The holder count is released in a `finally`.
88. Result: `{mediaId, created, linked, alreadyPresent, errors}`, logged. A re-run of the same relink lands in `alreadyPresent` (transfer) or returns the existing rows (in place: `linkExistingFileInPlace` returns the existing row, which counts as `linked`).
89. The in-place branch of rule 83 and `linkExistingFileInPlace` run for the identified path too under `within(Lc,...)`; the transfer branch resolves each source by rule 7; `scanRoot` is only an upper bound for a read-only climb. An in-place `reorganize` (no `transfer`, always a `move`) takes only sources with `within(Lc, realpath(filePath))`; any other is `errors[] = "<basename>: file outside the library root"`.
90. `relinkOrphans` takes the per-media lock of rule 27 around rules 83-87.
91. `scanRoot` is sanitized (`sanitizeFsPath`) and resolved but never used for a write.
92. `confirmImport(entries, method, {uniquifyOnCollision})`, per entry inside a `try` (a failure becomes `errors[] = "<basename>: <message>"` and the next entry runs): media by id (`Media #<id> not found`); `stat(entry.filePath)` (`<basename>: source file not found`); must be a regular file with a `VIDEO_EXTS` extension (`<basename>: not a video file`); `libraries.requirePathFor(targetLibraryId)`; the library must accept `media.type` (`<basename>: library "<name>" does not accept <type>`); **pin**: only when `media.libraryId` is null, `folderName = applyMovieFolderFormat(formats.movieFolder, {title, originalTitle, year, tmdbId})` (movie) or `applySeriesFolderFormat(formats.seriesFolder, {seriesTitle, originalTitle, year, tmdbId})`, checked by rule 3 before it is written, then `UPDATE media SET "libraryId", "folderName"`; a media of a different library is an `errors[]` entry (re-pinning a media that already has files would orphan every row, which the relink guard of rule 82 also prevents); then `libraryIngest.ingest({mediaId, files: [{path, episodeId}], transfer: method, fallbackQuality: entry.quality, sourceLabel: media.title, uniquifyOnCollision})`; `imported += result.imported.length`, `alreadyPresent += result.alreadyPresent.length`; when something was imported `mediaServers.dispatch('library.rescan', {title, path})` (detached).
93. Empty source directories are never removed after a `move`; companions of a moved file follow it (rule 14); `confirmImport` has no caller but rule 85.

### I. Plugin ingest

100. The plugin host method `library.ingest` calls `ingest` in process. `resolveAgainstGrantedRoots` `realpath`s every path (a missing path is an error) and accepts it when the path relative to `realpath(root)` is `''` or neither starts with `..` nor is absolute, for any root whose `realpath` succeeds; errors `library.ingest: "<path>" is outside every configured ingest root` and, with no roots or no registration, `library.ingest: no ingestRoots configured for plugin "<id>"`; each resolved path must also be a regular file (rule 7); then `ingest({mediaId, files, transfer, fallbackQuality, releaseName: sourceLabel, sourceLabel, replaceExisting: true})`; when something was imported, notifications `download.complete {title, quality: imported[0].quality, sourceTitle}` and media-servers `download.complete {title, path}` (detached); result `{imported: [{mediaFileId, relativePath, quality}], alreadyPresent, seasonNumber?, episodeNumber?}` (numbers only when exactly one file was imported with an episode). When nothing was imported and the ingest reported error entries (a truncated file, rule 21a), the call fails `ERR` with them joined by `; `.

### J. Notes

101. Existing folders are never renamed: `confirmImport` of a media that already has files in the same library follows the stored `folderName` (rule 18). The in-memory batch (rule 74) and queue (rule 34) lose work on restart and are not persisted. `settings.access` is the gate of rule 71 (no allow-list of source roots).

## SQL

Parameters `$n`:

- Ingest media: `SELECT m.*, l.* FROM media m LEFT JOIN libraries l ON l.id = m."libraryId" WHERE m.id = $1`.
- Episode of media: rule 20 (three lookups, one update of `"endNumber"`).
- Collision row: `SELECT * FROM media_files WHERE "mediaId" = $1 AND "relativePath" = $2 LIMIT 1`.
- File row: rule 24 (`UNIQUE ("mediaId","relativePath")`).
- Superseded: `SELECT mf.*, e.*, s.* FROM media_files mf LEFT JOIN media_file_items fi ON fi."mediaFileId" = mf.id LEFT JOIN items e ON e.id = fi."episodeId" LEFT JOIN item_groups s ON s.id = e."groupId" WHERE mf."mediaId" = $1 AND mf.id <> ALL($2)`.
- Rescan: `SELECT media + files + each file's episode (media_file_items) WHERE m.id = $1`; `DELETE FROM media_files WHERE id = ANY($1)`; `UPDATE media_files SET size = $3, quality = $4, "streamInfo" = $5, "updatedAt" = now WHERE id = $1`; `INSERT INTO item_parts` after a link or an insert; inserts of rule 44 and 45.
- Post-import: `SELECT mf.*, m.*, e.*, s.* FROM media_files mf JOIN media m... LEFT JOIN items e... LEFT JOIN item_groups s... WHERE mf.id = $1`; `UPDATE media_files SET "streamInfo" = $2, "osdbHash" = $3, "osdbBytesize" = $4 WHERE id = $1` (one `save`).
- Orphans: `SELECT mf.id, mf."relativePath", m.id, m."folderName", l.id, l.path FROM media_files mf JOIN media m ON m.id = mf."mediaId" JOIN libraries l ON l.id = m."libraryId" WHERE l.id = $1`.
- Relink: media by `(kind, provider, value)` in `media_external_ids`; media by `(library, type, "folderName")`; `UPDATE media SET "libraryId" = $1, "folderName" = $2 WHERE id = $3`; `DELETE FROM media WHERE id = $1` (rule 87); `SELECT count(*) FROM media_files WHERE "mediaId" = $1`.
- Settings: `SELECT value FROM app_settings WHERE key = 'companion_file_extensions' LIMIT 1`.
- FK facts the rules rely on (baseline): `media_files."mediaId"` CASCADE, `item_parts."mediaFileId"` and `item_parts."itemId"` CASCADE, `playback_states."mediaFileId"` SET NULL, `subtitle_files."mediaFileId"` CASCADE, `media_file_scans."mediaFileId"` CASCADE, `media."libraryId"` RESTRICT; unique `(mediaId, relativePath)` on `media_files`.
- Chapters: nothing in ingest writes them. Inserting an `item_parts` row or changing `media_files."streamInfo".chapters` makes triggers copy the probe chapters into `item_markers` (`items.md`, rules 25-27).

## Vectors/parity

Rust tests (`server/crates/server/src/ingest/tests.rs`) run only on generated trees under `/tmp/fliks-parity/` (temp dirs per test), asserting the final tree and every touched path. **No test or parity run writes to real media.** The `ingest-fs` unit tests are mandatory; each case asserts that nothing outside the temp library root changed (a sentinel file and directory mtime outside it, a recursive tree hash before and after).

Escape and safety cases (each runs for `copy` and `move`, as an ingest and, where it applies, through the relink route):

V1. `folderName` = `..`, `.`, `a/b`, `a\b`, absolute path, empty with a series, NUL, 300 bytes: rejected, nothing created (rule 3).
V2. Provider title `..`, `.`, `/`, `AC/DC`, `CON`, all-illegal characters: the folder name is validated, never `..` (rule 3, 4).
V3. Season folder format resolving to `..`: rejected.
V4. File name base empty, 300 bytes, ending in a space or dot; extension `.sh`, `.MKV`, none: rules 4.
V5. Symlinked media folder inside the root (target inside): allowed and written through; target outside the root: refused, nothing written (rule 5).
V6. Symlinked library root: `Lc` resolved, writes land under it.
V7. Library root missing, a file, unreadable: no `mkdir` of the root, error (rule 5).
V8. Source is a symlink to a regular file, to a directory, dangling, a FIFO, a directory named `x.mkv`: refused or resolved, `move` never relocates a link (rule 7).
V9. Source equals destination: no transfer, row linked (rule 13).
V10. Destination exists: `alreadyPresent`, bytes untouched; concurrent duplicate ingest: exactly one writer wins, the other `alreadyPresent`, no replaced file (rule 12); `uniquify` tries `(2)`..`(99)`, an error entry only when `(99)` is also taken.
V11. `replaceExisting` with equal size (no-op) and different size (replaced atomically, mode kept, stale EDL removed, row updated in place) (rules 22, 23).
V12. Cross-device: a `tmpfs` or bind-mounted second filesystem (`/dev/shm`) as the source, `move`: copy, `fsync`, rename, source unlinked; unlink failure (read-only source directory) still succeeds with a warning (rule 9). Skipped when no second filesystem is available.
V13. Copy interrupted (the test kills the copy after the temp exists): only `.fliks-tmp-*` remains; a new ingest of the same name succeeds; a temp last modified 25 hours ago is reaped, a fresh one and a non-regular entry are not (W3).
V14. Companions: `Movie.fr.srt`, `Movie.en.hi.forced.srt`, `Movie.edl` exact, `Movie-extras.edl` skipped, `Movie 2.srt` next to `Movie 2.mkv` not carried by `Movie.mkv`, two same-extension non-exact companions (second skipped, first kept), a symlink companion skipped, an existing destination companion kept (rules 14, 15).
V15. Season pack: three episodes, one unnumbered file linked as nothing; missing season/episode rows are never created by ingest (rules 19, 20).
V16. Superseded removal: movie replace (progress kept on the item, superseded file and EDL removed), series partial coverage keeps the superseded file, multi-episode range ends (`endEpisodeNumber` reset), a range file and a second version written as parts, a failing delete leaves the superseded file and row (rules 29-33).
V17. Rescan: missing `mediaDir` refuses and keeps rows (rule 39); unreadable subdirectory aborts removals only; bonus/sample skip; depth 4 skipped; a FIFO named `x.mkv` ignored; added/removed/updated counts after a file change (replace bytes: `size` and `streamInfo` refreshed, crop reset); an alien file in a series folder not added (rules 38-48).
V18. Orphan scan: grouping, root-level movie `folderName = ''`, a series file at the root dropped, `linkedSet` exclusion, sample/bonus skip, depth 3, nfo cap (rules 60-66).
V19. Relink: in place identified and unmatched, file outside the library root (400, nothing registered), `folderName` escape (rejected), `transfer` copy and move, `reorganize` in place, wrong-library media 400, unmatched created-then-nothing-linked deleted, re-run idempotent (rules 76-92).
V20. Post-import queue: de-duplication, one at a time, progress `current/total`, restart drops the backlog (rules 34-36); settle timer re-arm and the 5 min ceiling with a paused clock (rule 37).

Fixtures: `media-path` (lexical `relativePathUnderMediaRoot`; it compares components, so a file named `..foo.mkv` is accepted), `naming` (folder and file names), `release-parsing` (quality, titles) under `server/fixtures`. `server/parity/media-gen.sh` generates 2-second `testsrc` files and sidecars for the cases above.
