# appletv

Native **tvOS (Apple TV)** app for Fliks, in SwiftUI. tvOS exposes no
WebView, so the Angular client can't run here — this is a from-scratch
native UI talking to the same backend.

This is **P0**: project scaffolding + the remote-build toolchain + a
"hello" `RootView`. No data layer, no auth, no player yet.

## Development model

The tvOS toolchain (Xcode, `xcodebuild`, signing, Simulator, device deploy)
is macOS-only. Code here on the PC (monorepo context), build/debug on a Mac.

- **Edit + git**: on the Linux PC — canonical.
- **Build / sign / run / debug**: on the Mac (`ssh` host `mac`), the machine
  paired with the Apple TV.
- **Transport**: `rsync` over SSH.
- **Xcode project**: generated by **XcodeGen** from `project.yml` (the
  `.xcodeproj` isn't versioned, regenerated on every build).

Fliks is mono-tenant — there's no per-client config generation here. The
backend server address is entered by the user at runtime (a later phase),
not baked into the build.

## Wrapper `./appletv`

| Command | Effect |
|---|---|
| `./appletv run` | build + launch on the tvOS **Simulator** + pull a screenshot |
| `./appletv device` | build signed + install/launch on the paired **Apple TV** |
| `./appletv build` | build for the Simulator only |
| `./appletv sync` | rsync the project to the Mac |
| `./appletv logs` | stream Simulator logs |
| `./appletv open` | open the project in Xcode on the Mac (for VNC/debug) |

## Prerequisites

- `~/.ssh/config` with a `mac` host (keyless).
- XcodeGen on the Mac: `brew install xcodegen` (or build from source via
  `ssh mac 'bash ~/fliks-appletv-build/scripts/remote-build.sh install-xcodegen'`
  once the project has been synced).
- **Run on device**: an Apple ID added in Xcode (*Settings → Accounts*) for
  automatic signing, and `TV_UDID` set to the paired Apple TV's device UDID
  (`export TV_UDID=...` before `./appletv device`).

## First build

```bash
chmod +x appletv
./appletv run
```

## Placeholder art

`Sources/Resources/Assets.xcassets/App Icon & Top Shelf Image.brandassets`
has the correct tvOS icon/Top Shelf folder structure (front/middle/back
icon layers, Top Shelf Image, Top Shelf Image Wide) but no actual images —
drop real assets into each `.imageset` before shipping. The catalog isn't
wired via `ASSETCATALOG_COMPILER_APPICON_NAME` yet, so its absence doesn't
block this P0 build.
